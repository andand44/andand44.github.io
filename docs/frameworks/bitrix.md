# Bitrix

## Определение

Bitrix (торговая марка «1С-Битрикс») — это коммерческая платформа для разработки и управления веб-проектами: сайтами, интернет-магазинами, корпоративными порталами и бизнес-приложениями. В основе «1С-Битрикс: Управление сайтом» лежит собственный PHP-фреймворк (Bitrix Framework), который предоставляет готовые модули, компоненты, слой работы с данными (в том числе через инфоблоки), систему прав, кеширование и средства интеграции с 1С и внешними сервисами.

## Зачем нужно

- **Быстрая разработка.** Готовые компоненты, визуальные редакторы и админ-панель позволяют запускать проекты без написания всей логики с нуля.
- **Управление контентом и Commerce.** Встроенные инструменты для каталогов, заказов, оплат, скидок и CRM (в экосистеме Bitrix24).
- **Масштабируемость и интеграции.** Поддержка высокой нагрузки, кластеризации, интеграции с 1С, платёжными системами, маркетплейсами и REST API.
- **Единая экосистема.** Связка сайта, CRM, задач и сквозной аналитики в продуктах 1С-Битрикс и Bitrix24.
- **Для разработчиков.** PHP API, ORM-подобные возможности для инфоблоков, обработчики событий, шаблоны компонентов и возможность создавать сложную бизнес-логику.

## Пример

Пример использования Bitrix Framework и API инфоблоков для вывода списка активных элементов каталога:

```php
<?php
require($_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php');

use Bitrix\Main\Loader;

if (Loader::includeModule('iblock')) {
    $rsElements = CIBlockElement::GetList(
        ['SORT' => 'ASC'],
        ['IBLOCK_ID' => 5, 'ACTIVE' => 'Y'],
        false,
        false,
        ['ID', 'NAME', 'PREVIEW_TEXT', 'DETAIL_PAGE_URL']
    );

    while ($arElement = $rsElements->GetNext()) {
        echo '<a href="' . $arElement['DETAIL_PAGE_URL'] . '">' . htmlspecialchars($arElement['NAME']) . '</a><br>';
    }
}

require($_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/epilog_after.php');
?>
```
