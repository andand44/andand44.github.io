# Streamlit

### Определение

**Streamlit** — это опенсорсный Python-фреймворк, предназначенный для быстрого создания интерактивных веб-приложений и дашбордов для задач машинного обучения и анализа данных. Он позволяет разработчикам превращать обычные Python-скрипты в полноценные веб-интерфейсы без необходимости писать код на HTML, CSS или JavaScript.

### Зачем нужно

Streamlit значительно упрощает и ускоряет процесс разработки пользовательских интерфейсов для специалистов по данным (Data Scientists) и ML-инженеров. Основные цели использования:

* **Быстрое прототипирование:** Создание веб-приложений за считанные минуты прямо из Python-скрипта.
* **Визуализация данных:** Бесшовная интеграция с библиотеками анализа данных (Pandas, NumPy) и визуализации (Matplotlib, Plotly, Altair).
* **Демонстрация ML-моделей:** Удобный способ показать работу модели заказчикам или коллегам, предоставив им интерактивные элементы управления (слайдеры, кнопки, загрузку файлов).

### Пример

Ниже приведен простой пример кода на Python, который создает веб-страницу с заголовком, полем для ввода текста и интерактивным графиком.

```python
import streamlit as st
import pandas as pd
import numpy as np

# Устанавливаем заголовок приложения
st.title('Приветствие и случайный график')

# Создаем интерактивное поле для ввода имени
user_name = st.text_input('Как вас зовут?', 'Аноним')
st.write(f'Привет, {user_name}! Добро пожаловать в Streamlit.')

# Генерируем случайные данные для графика
data = pd.DataFrame(
    np.random.randn(50, 3),
    columns=['Колонка A', 'Колонка B', 'Колонка C']
)

# Отображаем линейный график
st.line_chart(data)
```

Чтобы запустить это приложение, достаточно сохранить код в файл `app.py` и выполнить команду в терминале:
```bash
streamlit run app.py
```
