# LangChain

### Определение

LangChain — это открытый фреймворк (open-source framework), предназначенный для упрощения создания приложений на базе больших языковых моделей (LLM). Он предоставляет стандартизированные интерфейсы, компоненты и инструменты для интеграции языковых моделей (таких как GPT-4, Claude, Llama) с внешними источниками данных, API и другими сервисами.

### Зачем нужно

Разработка сложных приложений с использованием LLM требует решения множества задач: управление контекстом, подключение к базам данных, создание цепочек запросов (chains) и агентов. LangChain решает эти проблемы, предлагая:

- **Модульность:** Легкая замена одних компонентов (например, LLM или векторных баз данных) на другие без переписывания всего кода.
- **Интеграция с данными:** Инструменты для загрузки, обработки и хранения данных (включая RAG - Retrieval-Augmented Generation), что позволяет моделям отвечать на основе актуальной или приватной информации.
- **Управление памятью:** Возможность сохранять историю сообщений и контекст диалога.
- **Агенты:** Создание автономных ИИ-агентов, которые могут выбирать инструменты и выполнять многошаговые задачи.

### Пример

Простой пример использования LangChain на Python для создания цепочки, которая генерирует название для компании, производящей определенный продукт:

```python
from langchain_openai import OpenAI
from langchain_core.prompts import PromptTemplate
from langchain.chains import LLMChain

# Инициализация языковой модели
llm = OpenAI(temperature=0.9)

# Создание шаблона промпта
prompt = PromptTemplate(
    input_variables=["product"],
    template="Придумай креативное название для компании, которая производит {product}?",
)

# Создание цепочки (Chain)
chain = LLMChain(llm=llm, prompt=prompt)

# Запуск цепочки
print(chain.run("экологичные зубные щетки"))
# Вывод: "ЭкоЩетка" или "Зеленая Улыбка"
```
