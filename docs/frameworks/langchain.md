# LangChain

### Определение

LangChain — это открытый фреймворк (open-source framework), предназначенный для упрощения создания приложений на базе больших языковых моделей (LLM). Он предоставляет стандартизированные интерфейсы, компоненты и инструменты для интеграции языковых моделей (таких как GPT-4, Claude, Llama и др.) с внешними источниками данных, API и другими сервисами. LangChain позволяет разработчикам связывать (chain) различные вызовы моделей и инструментов для создания сложных сценариев использования, таких как чат-боты, генерация кода, анализ документов и автономные агенты.

### Зачем нужно

Разработка приложений на базе LLM требует решения множества задач: управление контекстом, подключение к базам данных, вызов внешних API, сохранение истории сообщений и оркестрация сложных логических цепочек. LangChain решает эти проблемы, предлагая:
- **Модульность**: готовые компоненты для работы с промптами, моделями, памятью и индексами.
- **Интеграция с данными (RAG)**: возможность подключать векторные базы данных для поиска информации по корпоративным документам или базам знаний, что позволяет моделям отвечать на вопросы, выходящие за рамки их обучающих данных.
- **Управление памятью**: инструменты для сохранения состояния диалога (краткосрочная и долгосрочная память).
- **Агенты**: создание систем, в которых LLM может самостоятельно выбирать инструменты (например, поиск в интернете, калькулятор, выполнение кода) для решения поставленной задачи.

### Пример

Простейший пример использования LangChain на языке Python для создания цепочки (chain), которая генерирует название для компании, производящей определенный продукт:

```python
# Установка: pip install langchain langchain-openai
import os
from langchain_openai import OpenAI
from langchain.prompts import PromptTemplate
from langchain.chains import LLMChain

# Установка API ключа (рекомендуется через переменные окружения)
os.environ["OPENAI_API_KEY"] = "your-api-key"

# Инициализация языковой модели
llm = OpenAI(temperature=0.7)

# Создание шаблона промпта
prompt = PromptTemplate(
    input_variables=["product"],
    template="Придумай креативное название для компании, которая производит {product}.",
)

# Создание цепочки (Chain), объединяющей промпт и модель
chain = LLMChain(llm=llm, prompt=prompt)

# Запуск цепочки
result = chain.run("экологичные зубные щетки")
print(result)
```

В этом примере LangChain абстрагирует рутинную работу по формированию промптов и отправке запросов к API модели, позволяя разработчику сосредоточиться на логике приложения.
