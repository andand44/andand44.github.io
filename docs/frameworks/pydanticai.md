# PydanticAI

## Определение

**PydanticAI** — это Python-фреймворк для разработки агентов и приложений на базе генеративного ИИ, созданный командой разработчиков библиотеки Pydantic. Он переносит принципы строгой типизации, валидации данных и удобства разработки в экосистему больших языковых моделей (LLM). Фреймворк является модельно-независимым (model-agnostic) и поддерживает интеграцию с такими провайдерами, как OpenAI, Anthropic, Google Gemini и другими.

## Зачем нужно

Традиционное взаимодействие с LLM часто возвращает неструктурированный текст, который сложно надежно использовать в программном коде. PydanticAI решает эту проблему и необходим для:

1. **Гарантии структуры данных:** Автоматически преобразует и валидирует ответы нейросетей в соответствии с заданными Pydantic-моделями (Structured Outputs).
2. **Типобезопасности (Type Safety):** Обеспечивает надежность кода благодаря статической типизации и валидации данных на этапе выполнения.
3. **Внедрения зависимостей (Dependency Injection):** Упрощает передачу контекста, инструментов (tools), баз данных и API-клиентов в систему промптов и вызовов агента.
4. **Упрощения тестирования и мониторинга:** Предоставляет встроенные инструменты для мокирования ответов моделей и бесшовную интеграцию с платформой мониторинга Logfire.

## Пример

Ниже приведен пример создания простого ИИ-агента, который извлекает информацию и возвращает строго типизированный объект:

```python
from pydantic import BaseModel
from pydantic_ai import Agent

# 1. Описываем желаемую структуру ответа
class CityInfo(BaseModel):
    city: str
    country: str
    population: int

# 2. Инициализируем агента
agent = Agent(
    'openai:gpt-4o',
    result_type=CityInfo,
    system_prompt='Извлеки информацию о городе из текста пользователя.'
)

# 3. Выполняем запрос
result = agent.run_sync('Париж — столица Франции, в нем проживает около 2 миллионов человек.')

# 4. Получаем валидированный Pydantic-объект
print(result.data)
# Вывод: city='Париж' country='Франция' population=2000000
```

В этом примере PydanticAI автоматически сгенерирует JSON-схему на основе класса `CityInfo`, отправит её языковой модели и проверит полученный ответ на соответствие заявленным типам данных.
