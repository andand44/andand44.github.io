# LangGraph

### Определение

LangGraph — это библиотека (фреймворк) с открытым исходным кодом, разработанная в рамках экосистемы LangChain. Она предназначена для создания сложных, многоагентных и управляемых состоянием приложений на базе больших языковых моделей (LLM). В отличие от классических цепочек (DAG), LangGraph позволяет строить циклические графы, что дает возможность реализовывать логику с циклами, ветвлениями и сохранением состояния на каждом шаге выполнения.

### Зачем нужно

LangGraph решает ряд ключевых задач при разработке LLM-приложений:

1. **Управление состоянием (State Management):** Обеспечивает надежную передачу и сохранение контекста между различными этапами (узлами) работы приложения.
2. **Поддержка циклов (Cycles):** Позволяет создавать агентов, способных к итеративному выполнению задач (например, генерация кода, его выполнение, обработка ошибок и повторная генерация).
3. **Человек в контуре (Human-in-the-loop):** Дает возможность приостанавливать выполнение графа для проверки, корректировки или подтверждения действий человеком, а затем бесшовно продолжать работу.
4. **Многоагентность (Multi-agent systems):** Упрощает оркестрацию нескольких агентов, каждый из которых может иметь свою роль, инструменты и память в рамках единого рабочего процесса.

### Пример

Ниже приведен базовый пример на Python, демонстрирующий создание простого графа с двумя узлами, которые обмениваются сообщениями через общее состояние:

```python
from langgraph.graph import StateGraph, END
from typing import TypedDict, List

# 1. Определяем структуру состояния
class AgentState(TypedDict):
    messages: List[str]

# 2. Создаем функции-узлы
def first_node(state: AgentState):
    return {'messages': ['Привет от первого узла!']}

def second_node(state: AgentState):
    last_message = state['messages'][-1]
    return {'messages': [f'Второй узел получил: {last_message}']}

# 3. Инициализируем граф
workflow = StateGraph(AgentState)

# 4. Добавляем узлы в граф
workflow.add_node('node_1', first_node)
workflow.add_node('node_2', second_node)

# 5. Настраиваем маршрутизацию
workflow.set_entry_point('node_1')
workflow.add_edge('node_1', 'node_2')
workflow.add_edge('node_2', END)

# 6. Компилируем и запускаем
app = workflow.compile()
result = app.invoke({'messages': []})

print(result['messages'])
# Вывод: ['Привет от первого узла!', 'Второй узел получил: Привет от первого узла!']
```
