# LangGraph

### Определение

**LangGraph** — это фреймворк с открытым исходным кодом от создателей LangChain, предназначенный для создания надежных, управляемых состоянием и многоагентных приложений на базе больших языковых моделей (LLM). В отличие от классических цепочек (chains), LangGraph позволяет описывать рабочие процессы в виде циклических графов, где узлы представляют собой шаги вычислений или вызовы агентов, а ребра — логику переходов между ними.

### Зачем нужно

Стандартные подходы к разработке LLM-приложений часто строятся на направленных ациклических графах (DAG), которые не поддерживают циклы. Это ограничивает создание по-настоящему автономных агентов. LangGraph решает эту проблему и предлагает:

1. **Цикличность и ветвление:** Возможность создавать циклы, что позволяет агентам возвращаться к предыдущим шагам, исправлять ошибки, уточнять запросы или вызывать инструменты до достижения нужного результата.
2. **Управление состоянием (State Management):** Встроенная поддержка сохранения и передачи состояния (памяти) между всеми узлами графа на протяжении всего сеанса.
3. **Человек в контуре (Human-in-the-loop):** Возможность приостановить выполнение графа в любой момент для получения одобрения или корректировки от человека, а затем продолжить работу.
4. **Многоагентные системы (Multi-agent):** Удобные инструменты для оркестрации нескольких агентов, которые могут взаимодействовать и передавать задачи друг другу.

### Пример

Ниже приведен простой пример создания графа на LangGraph, который имитирует работу чат-бота с сохранением состояния:

```python
from typing import TypedDict
from langgraph.graph import StateGraph, END

# 1. Определяем структуру состояния
class AgentState(TypedDict):
    messages: list[str]

# 2. Создаем функцию-узел (нода), которая обрабатывает состояние
def chatbot_node(state: AgentState):
    # Имитация генерации ответа языковой моделью
    new_message = "Привет! Я LangGraph. Чем могу помочь?"
    return {"messages": state["messages"] + [new_message]}

# 3. Инициализируем граф с нашей структурой состояния
workflow = StateGraph(AgentState)

# 4. Добавляем узел в граф
workflow.add_node("chatbot", chatbot_node)

# 5. Устанавливаем точку входа и завершения
workflow.set_entry_point("chatbot")
workflow.add_edge("chatbot", END)

# 6. Компилируем граф в исполняемое приложение
app = workflow.compile()

# 7. Запускаем граф
inputs = {"messages": ["Здравствуйте!"]}
result = app.invoke(inputs)

print(result["messages"])
# Вывод: ['Здравствуйте!', 'Привет! Я LangGraph. Чем могу помочь?']
```
