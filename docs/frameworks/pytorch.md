# PyTorch

## Определение

PyTorch — это открытая библиотека машинного обучения на языке Python, разработанная в основном лабораторией Facebook AI Research (FAIR). Она предоставляет гибкую платформу для построения и обучения нейронных сетей, а также для выполнения тензорных вычислений с поддержкой GPU. Ключевой особенностью PyTorch является динамический вычислительный граф, который позволяет изменять архитектуру модели во время выполнения, что упрощает отладку и разработку.

## Зачем нужно

PyTorch широко используется для задач глубокого обучения: обработки изображений, текста, речи и многих других. Он нужен исследователям и разработчикам, поскольку:

- позволяет быстро прототипировать модели благодаря интуитивному императивному стилю;
- поддерживает автоматическое дифференцирование, что упрощает обучение нейросетей;
- имеет богатую экосистему: TorchVision, TorchText, TorchAudio, Hugging Face Transformers;
- обеспечивает высокую производительность на GPU/TPU;
- используется во многих production-системах и научных исследованиях.

## Пример

Простейший пример — создание и обучение линейной регрессии на PyTorch.

```python
import torch
import torch.nn as nn

# Данные: y = 2x + 1 + шум
x = torch.linspace(0, 1, 100).reshape(-1, 1)
y = 2 * x + 1 + torch.randn_like(x) * 0.1

# Модель: линейная регрессия
model = nn.Linear(1, 1)
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

# Обучение
for epoch in range(100):
    pred = model(x)
    loss = loss_fn(pred, y)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

print(f"Обученное значение: w = {model.weight.item():.2f}, b = {model.bias.item():.2f}")
```

После обучения модель приблизительно восстанавливает зависимость `y = 2x + 1`, демонстрируя базовый цикл работы с PyTorch.
