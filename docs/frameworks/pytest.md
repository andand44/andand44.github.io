# Pytest

## Определение
**Pytest** — это зрелый и полнофункциональный фреймворк для тестирования на языке Python. Он позволяет разработчикам писать компактные и читаемые тесты для любых типов приложений: от простых модульных (unit) тестов до сложных интеграционных и функциональных проверок API и баз данных.

## Зачем нужно
Pytest используется для автоматизации проверки кода и повышения качества программного обеспечения. Основные причины его популярности:
- **Минимум шаблонного кода:** Тесты пишутся как обычные функции, а для проверок используется стандартный оператор `assert`, что делает код чище по сравнению со встроенным модулем `unittest`.
- **Мощная система фикстур (fixtures):** Позволяет легко управлять предусловиями и состоянием тестов (например, создание тестовой базы данных или моков), переиспользуя код.
- **Параметризация:** Возможность запускать один и тот же тест с разными наборами входных данных.
- **Огромная экосистема:** Поддержка сотен плагинов (например, `pytest-cov` для покрытия кода, `pytest-asyncio` для асинхронного кода, `pytest-django` для Django).
- **Легкая интеграция:** Бесшовно встраивается в пайплайны CI/CD.

## Пример
Установка фреймворка:
```bash
pip install pytest
```

Допустим, у нас есть файл `math_functions.py` с функцией деления:
```python
# math_functions.py
def divide(a, b):
    if b == 0:
        raise ValueError("Cannot divide by zero!")
    return a / b
```

Тесты для этой функции помещаем в файл `test_math_functions.py`:
```python
# test_math_functions.py
import pytest
from math_functions import divide

def test_divide_success():
    assert divide(10, 2) == 5

def test_divide_by_zero():
    # Проверяем, что функция вызывает исключение
    with pytest.raises(ValueError):
        divide(10, 0)
```

Чтобы запустить тесты, достаточно выполнить команду в терминале:
```bash
pytest
```
Pytest автоматически обнаружит файлы и функции с префиксом `test_` и выведет понятный отчет о прохождении проверок.
