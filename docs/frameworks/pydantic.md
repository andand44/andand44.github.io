# Pydantic

## Определение
Pydantic — это библиотека Python для валидации данных и управления настройками приложений на основе аннотаций типов. Она позволяет определять модели данных как классы с типизированными полями и автоматически проверять, преобразовывать и сериализовать входные данные.

## Зачем нужно
Pydantic решает проблему ручной проверки данных, которая часто приводит к ошибкам и избыточному коду. С её помощью можно:

- декларативно описывать структуру данных;
- автоматически валидировать типы и значения полей;
- преобразовывать входные данные из JSON, словарей и других источников в объекты Python;
- получать понятные сообщения об ошибках;
- использовать встроенную поддержку сериализации в JSON и обратно;
- интегрироваться с FastAPI, SQLAlchemy и другими инструментами.

Pydantic особенно полезен при работе с API, конфигурациями и парсингом внешних данных, где важна надёжность и строгость типов.

## Пример

```python
from pydantic import BaseModel, ValidationError

class User(BaseModel):
    name: str
    age: int
    email: str

try:
    user = User(name='Alice', age='30', email='alice@example.com')
    print(user)
    print(user.model_dump_json())
except ValidationError as e:
    print(e)
```

В этом примере Pydantic автоматически преобразует строку `'30'` в целое число `30`, проверяет корректность переданных полей и позволяет легко сериализовать объект в JSON.
