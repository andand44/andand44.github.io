# Tailwind CSS

## Определение

Tailwind CSS — это utility-first CSS-фреймворк с открытым исходным кодом, который предоставляет набор низкоуровневых классов-утилит для построения интерфейсов непосредственно в HTML. Вместо готовых компонентов он даёт гибкие примитивы: отступы, цвета, типографику, flexbox, grid и другие.

## Зачем нужно

Tailwind CSS ускоряет разработку интерфейсов, позволяя стилизовать элементы без написания отдельного CSS. Он обеспечивает консистентность дизайн-системы, упрощает поддержку кода, автоматически удаляет неиспользуемые стили в продакшене и легко настраивается через конфигурационный файл.

## Пример

Создание кнопки с использованием Tailwind CSS:

```html
<button class="bg-blue-500 hover:bg-blue-700 text-white font-bold py-2 px-4 rounded">
  Нажми меня
</button>
```

Вместо отдельного CSS-файла со стилями для кнопки, все нужные стили задаются прямо в классах. Это делает разметку наглядной и снижает количество переключений между HTML и CSS.
