# OrcaRouter

### Определение

**OrcaRouter** — это интеллектуальный маршрутизатор (роутер) запросов, предназначенный для эффективного распределения промптов между различными большими языковыми моделями (LLM), с особым акцентом на семейство моделей Orca. Он выступает в качестве промежуточного слоя (middleware), который анализирует сложность, контекст и требования входящего запроса, после чего направляет его к наиболее подходящей модели или вычислительному узлу.

### Зачем нужно

В современной разработке приложений на базе ИИ часто требуется использовать сразу несколько языковых моделей для баланса между качеством ответов, скоростью и стоимостью. OrcaRouter необходим для:

- **Оптимизации расходов:** Автоматическое перенаправление простых запросов к легковесным и экономичным моделям, а сложных аналитических задач — к более мощным (и дорогим) версиям.
- **Повышения производительности:** Снижение времени отклика за счет балансировки нагрузки и выбора оптимального эндпоинта.
- **Упрощения архитектуры:** Предоставление разработчикам единого API для взаимодействия с пулом моделей, скрывая внутреннюю логику маршрутизации.
- **Обеспечения отказоустойчивости:** Автоматическое переключение на резервные модели в случае сбоев или высокой задержки основного узла.

### Пример

Ниже представлен концептуальный пример использования OrcaRouter в Python:

```python
from orcarouter import OrcaRouter

# Инициализация роутера с пулом доступных моделей
router = OrcaRouter(
    models={
        'fast': 'orca-mini-3b',
        'balanced': 'orca-medium-7b',
        'powerful': 'orca-large-13b'
    }
)

# Простой запрос (будет отправлен на легкую модель)
query_1 = 'Переведи привет на английский.'
response_1 = router.route(query_1)
print(f'Использована модель: {response_1.model_name}')
print(f'Ответ: {response_1.content}\n')

# Сложный запрос (будет отправлен на мощную модель)
query_2 = 'Проанализируй временную сложность алгоритма быстрой сортировки и предложи оптимизации.'
response_2 = router.route(query_2)
print(f'Использована модель: {response_2.model_name}')
print(f'Ответ: {response_2.content}')
```

В данном примере OrcaRouter автоматически оценивает входящие промпты: первый запрос (перевод) будет обработан быстрой и дешевой моделью `orca-mini-3b`, а второй (анализ алгоритмов) будет передан более мощной `orca-large-13b` для получения качественного результата.
