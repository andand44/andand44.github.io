# LLM

## Определение

**LLM** (Large Language Model, большая языковая модель) — это класс моделей машинного обучения, основанных на нейронных сетях (чаще всего на архитектуре Transformer), которые обучаются на очень больших массивах текстовых данных. Цель обучения — предсказание следующего слова (токена) в последовательности, что позволяет модели улавливать грамматику, факты, рассуждения и стилистику естественного языка. Современные LLM содержат от сотен миллионов до триллионов параметров и могут решать множество языковых задач без дополнительного обучения или после небольшой донастройки (fine-tuning).

## Зачем нужно

LLM применяются там, где требуется работа с естественным языком:

- **Генерация текста**: статьи, письма, описания товаров, творческие истории.
- **Понимание и анализ**: классификация тональности, извлечение сущностей, ответы на вопросы по документам.
- **Диалоговые системы**: чат-боты, виртуальные ассистенты, поддержка пользователей.
- **Перевод и локализация**: машинный перевод с сохранением контекста.
- **Помощь в программировании**: генерация кода, объяснение ошибок, рефакторинг.
- **Обобщение и поиск**: краткое изложение длинных текстов, семантический поиск.

Главное преимущество LLM — универсальность: одна модель может выполнять разные задачи по текстовой инструкции (prompt), часто в режиме zero-shot или few-shot, без обучения отдельной модели под каждую задачу.

## Пример

Пример использования LLM через библиотеку `transformers` от Hugging Face:

```python
from transformers import pipeline

# Создаём пайплайн генерации текста
generator = pipeline('text-generation', model='gpt2')

# Отправляем запрос (промпт) модели
prompt = 'Большая языковая модель — это'
result = generator(prompt, max_length=60, num_return_sequences=1)

print(result[0]['generated_text'])
```

Возможный вывод модели:

```text
Большая языковая модель — это нейронная сеть, обученная на огромном количестве текстов, которая умеет понимать и генерировать человеческий язык для решения различных задач...
```

В промышленных приложениях вместо локальной модели часто обращаются к облачным LLM (например, GPT-4, Claude, Llama 2) через API, передавая промпт и получая готовый ответ.
