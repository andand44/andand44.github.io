# nomic-embed-text

## Определение
`nomic-embed-text` — это высокопроизводительная модель машинного обучения с открытым исходным кодом от компании Nomic AI, предназначенная для генерации текстовых эмбеддингов (векторных представлений). Она преобразует слова, предложения или документы в многомерные числовые векторы, отражающие их семантическое значение. Модель поддерживает длинный контекст и может быть развернута локально (например, через Ollama).

## Зачем нужно
Модель используется для задач, требующих понимания смысла текста и вычисления семантической близости. Основные сценарии применения:
- **Семантический поиск:** поиск информации по смыслу, а не по ключевым словам.
- **RAG (Retrieval-Augmented Generation):** извлечение релевантного контекста из базы знаний для генерации точных ответов языковыми моделями.
- **Кластеризация и классификация:** группировка документов по смыслу или тематике.
- **Рекомендательные системы:** поиск похожего контента на основе векторного сравнения.

## Пример
Пример использования `nomic-embed-text` через Python-библиотеку Ollama для получения вектора текста:

```python
import ollama

# Генерация эмбеддинга
response = ollama.embeddings(
    model='nomic-embed-text',
    prompt='Технологии искусственного интеллекта развиваются очень быстро.'
)

# Извлечение вектора
vector = response['embedding']

print(f"Размерность вектора: {len(vector)}")
print(f"Первые 5 элементов: {vector[:5]}")
```
