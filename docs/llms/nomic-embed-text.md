# nomic-embed-text

## Определение

`nomic-embed-text` — это высокопроизводительная модель для генерации текстовых эмбеддингов (векторных представлений) с открытым исходным кодом, разработанная компанией Nomic AI. Она преобразует слова, предложения или целые документы в многомерные числовые векторы, которые отражают их семантическое значение. Модель отличается увеличенным контекстным окном (до 8192 токенов) и может быть развернута локально (например, с помощью Ollama), что делает её отличной альтернативой проприетарным решениям вроде OpenAI `text-embedding-3`.

## Зачем нужно

Основная задача `nomic-embed-text` — обеспечить машину возможностью понимать смысловую близость текстов. Это критически важно для следующих сценариев:

1. **Семантический поиск:** поиск информации по смыслу, а не по точному совпадению ключевых слов.
2. **RAG (Retrieval-Augmented Generation):** извлечение релевантных фрагментов данных из внешних баз знаний для передачи их в качестве контекста генеративным LLM (например, Llama 3 или GPT-4), что повышает точность ответов.
3. **Кластеризация и классификация:** автоматическая группировка документов по темам без предварительной разметки.
4. **Конфиденциальность и экономия:** возможность локального запуска позволяет компаниям не передавать чувствительные данные в облачные API и экономить на запросах.

## Пример

Ниже приведен пример использования `nomic-embed-text` на Python с помощью библиотеки `ollama` для векторизации текста:

```python
import ollama

# Инициализация запроса к модели для получения эмбеддинга
response = ollama.embeddings(
    model='nomic-embed-text',
    prompt='Искусственный интеллект меняет подход к разработке программного обеспечения.'
)

# Извлечение вектора из ответа
embedding_vector = response['embedding']

print(f'Длина вектора: {len(embedding_vector)}')
print(f'Первые 5 значений: {embedding_vector[:5]}')
```

В данном примере текст преобразуется в числовой массив (вектор). Этот вектор затем можно сохранить в векторную базу данных (например, Chroma, Qdrant или pgvector) и использовать для быстрого поиска похожих документов по смысловому запросу.
