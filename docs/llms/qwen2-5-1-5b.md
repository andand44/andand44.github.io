# qwen2.5:1.5b

## Определение
Qwen2.5:1.5b — это компактная открытая большая языковая модель (LLM) из семейства Qwen2.5, разработанная Alibaba Cloud. Число «1.5b» означает около 1.5 миллиарда параметров. Модель выпускается в вариантах для продолжения текста (base) и для диалогов/инструкций (Instruct, например `Qwen2.5-1.5B-Instruct`). Она распространяется с открытыми весами (преимущественно по лицензии Apache 2.0) и предназначена для понимания и генерации естественного языка, а также для решения задач вроде суммаризации, ответов на вопросы и генерации кода.

## Зачем нужно
- **Локальный запуск и приватность.** Небольшой размер позволяет развернуть модель на собственном сервере или ПК, не передавая данные третьим лицам.
- **Низкие требования к ресурсам.** Благодаря квантованию (4-bit, 8-bit) модель может работать на GPU с 4–8 ГБ памяти или даже на CPU, что делает её доступной для edge-устройств.
- **Быстрый отклик.** Малое количество параметров обеспечивает низкую задержку по сравнению с моделями на 7B+ параметров.
- **Открытость и кастомизация.** Доступ к весам позволяет проводить дообучение (fine-tuning), использовать LoRA/QLoRA и адаптировать модель под узкие домены.
- **Мультиязычность.** Модель обучена на большом массиве данных на многих языках, включая английский, китайский и русский, что упрощает создание многоязычных ассистентов.

## Пример
Пример запуска модели через Ollama:
```
ollama run qwen2.5:1.5b
```
После загрузки можно отправить запрос:
```
>>> Напиши короткое стихотворение про осень на русском языке.
```

Пример использования через библиотеку `transformers`:
```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = 'Qwen/Qwen2.5-1.5B-Instruct'
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name, device_map='auto')

messages = [
    {'role': 'user', 'content': 'Объясни, что такое JSON, простыми словами.'}
]
text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
inputs = tokenizer(text, return_tensors='pt').to(model.device)
outputs = model.generate(**inputs, max_new_tokens=200)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```
