# GigaChat

## Определение

GigaChat — это мультимодальная нейросетевая модель от Сбера, предназначенная для генерации текста, изображений, кода и диалогового общения. Модель основана на архитектуре Transformer и поддерживает русский и английский языки, а также может работать с визуальными запросами.

## Зачем нужно

GigaChat применяется для автоматизации общения с пользователями, создания ассистентов, генерации контента, помощи в программировании, образования и бизнес-задач. Она позволяет обрабатывать естественный язык, понимать контекст, отвечать на сложные вопросы и генерировать изображения по описанию. Благодаря доступности через API и интеграции в экосистему Сбера, GigaChat упрощает разработку интеллектуальных сервисов.

## Пример

Пример использования GigaChat через API на Python:

```python
import requests

url = "https://gigachat.devices.sberbank.ru/api/v1/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_TOKEN",
    "Content-Type": "application/json"
}

data = {
    "model": "GigaChat",
    "messages": [
        {"role": "user", "content": "Напиши краткое приветствие для клиента"}
    ]
}

response = requests.post(url, headers=headers, json=data)
print(response.json()["choices"][0]["message"]["content"])
```

Такой запрос вернёт сгенерированный текст от GigaChat, который можно использовать в чат-ботах, CRM или других приложениях.
