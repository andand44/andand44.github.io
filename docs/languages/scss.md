# SCSS

## Определение
SCSS (Sassy CSS) — это расширение языка CSS, представляющее собой один из синтаксисов препроцессора Sass. Оно добавляет в таблицы стилей программные возможности, такие как переменные, вложенность правил, миксины (примеси) и математические операции. Главная особенность SCSS заключается в том, что он полностью совместим с обычным CSS: любой валидный CSS-код является валидным SCSS-кодом.

## Зачем нужно
Использование SCSS значительно упрощает разработку и поддержку стилей в крупных и сложных проектах. Основные причины использования:
- **Переменные:** позволяют хранить значения (цвета, шрифты, размеры) в одном месте и легко изменять их во всем проекте.
- **Вложенность (Nesting):** делает код более читаемым, позволяя структурировать CSS-правила в соответствии с иерархией HTML-элементов.
- **Миксины (Mixins) и функции:** дают возможность переиспользовать повторяющиеся блоки стилей и избежать дублирования кода (принцип DRY).
- **Модульность:** позволяет разбивать стили на небольшие файлы (partials) и объединять их при компиляции, что упрощает командную работу и структуру проекта.

## Пример
Пример SCSS-кода с использованием переменных, миксинов и вложенности:

```scss
// Переменные
$primary-color: #3498db;
$padding: 16px;

// Миксин для кроссбраузерного скругления углов
@mixin border-radius($radius) {
  -webkit-border-radius: $radius;
     -moz-border-radius: $radius;
          border-radius: $radius;
}

// Вложенность селекторов
.card {
  padding: $padding;
  background-color: #ffffff;
  
  .card-title {
    color: $primary-color;
    font-size: 1.5rem;
  }
  
  .card-button {
    @include border-radius(8px);
    background-color: $primary-color;
    padding: $padding / 2;
    color: white;
    border: none;
    
    // Использование родительского селектора
    &:hover {
      background-color: darken($primary-color, 10%);
      cursor: pointer;
    }
  }
}
```

После компиляции этот SCSS-файл превращается в стандартный CSS-код, понятный любому веб-браузеру.
