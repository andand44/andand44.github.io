# SCSS

## Определение
SCSS (Sassy CSS) — это расширение языка CSS, которое добавляет в него возможности сценарного языка, такие как переменные, вложенность, миксины (mixins), наследование и функции. SCSS является одним из синтаксисов препроцессора Sass (Syntactically Awesome Style Sheets). В отличие от оригинального синтаксиса Sass (основанного на отступах), SCSS полностью совместим с обычным CSS, что означает, что любой валидный CSS-код является валидным SCSS-кодом.

## Зачем нужно
Использование SCSS необходимо для упрощения и ускорения разработки стилей, а также для повышения их поддерживаемости и масштабируемости. Основные преимущества:
- **Переменные:** позволяют хранить значения (цвета, шрифты, отступы) в одном месте и переиспользовать их по всему проекту.
- **Вложенность (Nesting):** дает возможность писать селекторы внутри других селекторов, что делает код более читаемым и логически структурированным, повторяя иерархию HTML-разметки.
- **Миксины (Mixins):** позволяют создавать переиспользуемые группы CSS-свойств, которые можно применять к разным селекторам, в том числе с передачей аргументов.
- **Наследование (Extend/Inheritance):** дает возможность одному селектору наследовать стили другого, избегая дублирования кода.
- **Операции и функции:** позволяют выполнять математические вычисления и преобразования цветов прямо в таблицах стилей.

## Пример
Ниже приведен пример использования переменных, вложенности и миксинов в SCSS:

```scss
// Объявление переменных
$primary-color: #3498db;
$padding: 16px;

// Объявление миксина
@mixin border-radius($radius) {
  -webkit-border-radius: $radius;
  -moz-border-radius: $radius;
  border-radius: $radius;
}

// Использование вложенности, переменных и миксинов
.card {
  padding: $padding;
  background-color: #fff;
  @include border-radius(8px);

  .card-title {
    color: $primary-color;
    font-size: 1.5em;
  }

  .card-body {
    margin-top: $padding / 2;
    
    &:hover {
      background-color: darken(#fff, 5%);
    }
  }
}
```

Этот SCSS-код при компиляции превращается в стандартный CSS, понятный любому браузеру.
