# Bash

## Определение
**Bash** (Bourne-Again SHell) — это командная оболочка и язык сценариев (скриптов), разработанный Брайаном Фоксом для проекта GNU. Является стандартным интерпретатором командной строки в большинстве Linux-дистрибутивов и macOS. Bash позволяет пользователям вводить команды для взаимодействия с операционной системой, управления файлами, запуска программ и написания автоматизированных сценариев.

## Зачем нужно
Bash необходим для эффективного управления компьютером и автоматизации рутинных задач. Основные причины использования:
- **Автоматизация:** Написание скриптов для выполнения повторяющихся действий (резервное копирование, обновление ПО, обработка логов).
- **Системное администрирование:** Управление процессами, пользователями, правами доступа и сетевыми настройками на серверах и локальных машинах.
- **Гибкая обработка данных:** Использование конвейеров (pipes) для передачи результатов одной команды другой, что позволяет решать сложные задачи анализа и преобразования данных прямо в терминале.
- **Разработка и DevOps:** Bash-скрипты широко применяются для сборки проектов, запуска тестов и развертывания приложений (CI/CD).

## Пример
Пример простого Bash-скрипта, который проверяет, запущен ли определенный процесс (например, `nginx`), и выводит соответствующий статус:

```bash
#!/bin/bash

PROCESS_NAME="nginx"

# Ищем процесс в списке запущенных
if pgrep -x "$PROCESS_NAME" > /dev/null
then
    echo "Процесс $PROCESS_NAME запущен."
else
    echo "Процесс $PROCESS_NAME не запущен."
fi
```

**Разбор примера:**
- `#!/bin/bash` — указывает системе использовать Bash для выполнения скрипта.
- `pgrep -x "$PROCESS_NAME"` — ищет процесс с точным именем `nginx`.
- `> /dev/null` — скрывает вывод команды `pgrep`, так как нам важен только факт успешного поиска (код возврата).
- Конструкция `if...then...else` проверяет результат поиска и выводит понятное сообщение для пользователя.
