# CSS3

### Определение

CSS3 (Cascading Style Sheets, уровень 3) — это новейшая версия языка стилей, используемого для описания внешнего вида документов, написанных на HTML или XML. CSS3 расширяет возможности предыдущих версий, добавляя модули для анимации, переходов, закруглений, теней, градиентов, гибкой верстки (Flexbox), grid-раскладки, медиазапросов и множества других современных визуальных эффектов.

### Зачем нужно

CSS3 позволяет разработчикам отделять содержание страницы от её оформления, упрощая поддержку и изменение дизайна. С его помощью можно создавать адаптивные интерфейсы, работающие на различных устройствах, улучшать пользовательский опыт за счет плавных анимаций и интерактивных элементов, а также ускорять загрузку сайтов, заменяя изображения чисто CSS-эффектами. Модульность CSS3 дает возможность использовать только необходимые функции, а также обеспечивает лучшую совместимость с современными браузерами.

### Пример

Ниже приведен простой пример использования CSS3 для создания карточки с закругленными углами, тенью и плавным переходом при наведении:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Пример CSS3</title>
  <style>
    .card {
      width: 300px;
      padding: 20px;
      margin: 50px auto;
      background: linear-gradient(135deg, #667eea, #764ba2);
      border-radius: 15px;
      box-shadow: 0 10px 20px rgba(0, 0, 0, 0.2);
      color: white;
      font-family: Arial, sans-serif;
      transition: transform 0.3s ease, box-shadow 0.3s ease;
    }

    .card:hover {
      transform: translateY(-10px);
      box-shadow: 0 20px 30px rgba(0, 0, 0, 0.3);
    }
  </style>
</head>
<body>
  <div class="card">
    <h3>Заголовок карточки</h3>
    <p>Этот блок использует возможности CSS3: градиент, тень, скругление и анимацию при наведении.</p>
  </div>
</body>
</html>
```

В этом примере применяются такие свойства CSS3, как `linear-gradient`, `border-radius`, `box-shadow` и `transition`, которые делают страницу более современной и привлекательной без использования дополнительных изображений или JavaScript.
