# Vanilla JS

## Определение

Vanilla JS (или "чистый JavaScript") — это термин, обозначающий использование JavaScript без дополнительных библиотек и фреймворков, таких как React, Angular или Vue. Это стандартный язык веб-браузеров, который поддерживается всеми современными браузерами и позволяет создавать динамические веб-страницы и приложения.

## Зачем нужно

Несмотря на обилие современных фреймворков, Vanilla JS остаётся фундаментом веб-разработки. Он нужен для:

- Быстрой загрузки страниц и приложений, поскольку не требует подключения внешних библиотек.
- Глубокого понимания работы JavaScript и веб-платформы в целом.
- Создания простых и легковесных решений, когда не требуется сложный инструментарий.
- Базовой подготовки перед изучением фреймворков — многие концепции (DOM, события, асинхронность) одинаково важны.
- Обеспечения совместимости и снижения зависимости от стороннего кода.

## Пример

Кнопка, которая при нажатии добавляет элемент в список, без использования фреймворков:

```html
<!DOCTYPE html>
<html>
<head>
  <title>Vanilla JS Example</title>
</head>
<body>
  <button id="add-btn">Добавить элемент</button>
  <ul id="list"></ul>

  <script>
    const button = document.getElementById('add-btn');
    const list = document.getElementById('list');

    button.addEventListener('click', () => {
      const li = document.createElement('li');
      li.textContent = 'Новый элемент';
      list.appendChild(li);
    });
  </script>
</body>
</html>
```

Vanilla JS даёт разработчику полный контроль над поведением интерфейса и является основой любого современного фронтенда.
