# HTML5

## Определение

HTML5 — это пятая major-версия стандарта HyperText Markup Language, используемого для структурирования и представления содержимого во Всемирной паутине. Он определяет семантические теги, мультимедийные элементы, графические API и улучшенные возможности для работы с формами, что позволяет создавать современные веб-приложения без сторонних плагинов.

## Зачем нужно

HTML5 нужен для создания семантически корректных, доступных и кросс-браузерных веб-страниц. Он упрощает разработку, обеспечивая встроенную поддержку аудио, видео, векторной графики и локального хранения данных. Благодаря новым элементам, таким как `<header>`, `<nav>`, `<main>`, `<article>` и `<footer>`, улучшается структура документа и его индексация поисковыми системами. Также HTML5 является основой для прогрессивных веб-приложений и тесно интегрируется с CSS3 и JavaScript.

## Пример

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Пример HTML5</title>
</head>
<body>
    <header>
        <h1>Мой сайт</h1>
        <nav>
            <ul>
                <li><a href="#home">Главная</a></li>
                <li><a href="#about">О нас</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <article>
            <h2>Статья</h2>
            <p>Это пример семантической разметки на HTML5.</p>
        </article>

        <section>
            <h2>Видео</h2>
            <video controls width="320">
                <source src="movie.mp4" type="video/mp4">
                Ваш браузер не поддерживает HTML5-видео.
            </video>
        </section>
    </main>

    <footer>
        <p>&copy; 2025</p>
    </footer>
</body>
</html>
```
