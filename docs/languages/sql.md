# SQL

## Определение

SQL (Structured Query Language) — это декларативный язык программирования, который используется для создания, модификации, управления и извлечения данных из реляционных баз данных. Он является стандартом де-факто для взаимодействия с системами управления базами данных (СУБД).

## Зачем нужно

SQL необходим для эффективной работы с большими объемами структурированных данных. Основные цели использования SQL:
- **Извлечение данных:** выполнение сложных выборок, фильтрация, сортировка и агрегация информации.
- **Манипуляция данными:** добавление, обновление и удаление записей в таблицах.
- **Управление структурой:** создание и изменение таблиц, индексов, представлений и связей между ними.
- **Безопасность и целостность:** настройка прав доступа и поддержание согласованности данных.

## Пример

Ниже приведен пример SQL-запроса, который выбирает имена и email-адреса пользователей из таблицы `users`, которым больше 18 лет, и сортирует результат по имени в алфавитном порядке:

```sql
SELECT name, email
FROM users
WHERE age > 18
ORDER BY name ASC;
```
