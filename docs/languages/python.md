# Python

## Определение
Python — это высокоуровневый, интерпретируемый язык программирования общего назначения с динамической типизацией и автоматическим управлением памятью. Он был создан Гвидо ван Россумом и впервые выпущен в 1991 году. Основной акцент в языке делается на читаемость кода и продуктивность разработчика.

## Зачем нужно
Python используется в самых разных областях благодаря своей простоте и обширной экосистеме библиотек:
- **Веб-разработка:** создание серверной части приложений (Django, Flask, FastAPI).
- **Data Science и Машинное обучение:** анализ данных, построение моделей ИИ (Pandas, NumPy, Scikit-learn, TensorFlow, PyTorch).
- **Автоматизация:** написание скриптов для автоматизации рутинных задач (системное администрирование, парсинг веб-страниц).
- **Разработка ПО:** создание десктопных приложений и игр.

## Пример
Простой пример программы на Python, которая выводит приветствие и вычисляет сумму двух чисел:

```python
def greet(name):
    return f"Привет, {name}!"

def add_numbers(a, b):
    return a + b

# Использование функций
print(greet("Мир"))
result = add_numbers(5, 3)
print(f"Сумма чисел: {result}")
```
