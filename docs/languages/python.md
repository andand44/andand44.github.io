# Python

## Определение
Python — это высокоуровневый, интерпретируемый язык программирования общего назначения с динамической типизацией и автоматическим управлением памятью. Он был создан Гвидо ван Россумом и впервые выпущен в 1991 году. Основной акцент в языке делается на читаемость кода и продуктивность разработчика, чему способствует использование отступов для определения блоков кода.

## Зачем нужно
Python используется в самых разных областях благодаря своей универсальности, простому синтаксису и огромной экосистеме библиотек:
- **Веб-разработка:** Создание серверной части приложений (фреймворки Django, Flask, FastAPI).
- **Data Science и Машинное обучение:** Анализ данных, построение моделей ИИ (библиотеки Pandas, NumPy, Scikit-learn, PyTorch, TensorFlow).
- **Автоматизация:** Написание скриптов для автоматизации рутинных задач, парсинга данных и системного администрирования.
- **Разработка ПО и прототипирование:** Быстрое создание прототипов и готовых десктопных приложений.

## Пример
Простая программа на Python, которая выводит приветствие и вычисляет сумму чисел в списке:

```python
# Определение функции
def greet(name):
    return f"Привет, {name}!"

# Работа со списком
numbers = [1, 2, 3, 4, 5]
total = sum(numbers)

# Вывод результатов
print(greet("Мир"))
print(f"Сумма чисел: {total}")
```
