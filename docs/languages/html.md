# HTML

## Определение

**HTML** (HyperText Markup Language, «язык гипертекстовой разметки») — стандартизированный язык разметки, используемый для создания и структурирования веб-страниц и веб-приложений. Документ HTML состоит из иерархии элементов, которые обозначаются тегами, например `<h1>`, `<p>`, `<a>`. В отличие от языков программирования, HTML не описывает логику, а задаёт смысловую и визуальную структуру контента.

## Зачем нужно

HTML решает несколько ключевых задач:

- **Структура документа.** Позволяет размечать заголовки, абзацы, списки, таблицы, формы и другие блоки.
- **Семантика и доступность.** Современные теги (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`) помогают браузерам, скринридерам и поисковым системам понимать назначение частей страницы.
- **Связь с другими технологиями.** HTML работает в связке с CSS (оформление) и JavaScript (интерактивность), формируя основу клиентской веб-разработки.
- **Кроссплатформенность.** Это открытый стандарт, который поддерживается всеми современными браузерами и устройствами.

## Пример

Простейшая HTML-страница:

```html
<!DOCTYPE html>
<html lang='ru'>
<head>
  <meta charset='UTF-8'>
  <title>Пример страницы</title>
</head>
<body>
  <header>
    <h1>Привет, мир!</h1>
  </header>
  <main>
    <p>Это пример простой веб-страницы на HTML.</p>
    <a href='https://example.com'>Перейти на Example</a>
  </main>
</body>
</html>
```

В этом примере `<!DOCTYPE html>` объявляет тип документа, тег `<html>` является корневым, `<head>` содержит метаданные, а `<body>` — видимое содержимое страницы.
