# HTML

## Определение

HTML (HyperText Markup Language) — это стандартный язык разметки для создания веб-страниц и веб-приложений. Он описывает структуру документа с помощью элементов (тегов), таких как заголовки, абзацы, списки, ссылки, изображения и формы. HTML не является языком программирования: он не содержит логики, а лишь определяет содержимое и его семантику.

## Зачем нужно

HTML используется для:
- определения структуры веб-документа;
- обеспечения доступности и семантики контента для браузеров, поисковых систем и вспомогательных технологий;
- встраивания медиа, ссылок и интерактивных элементов;
- совместной работы с CSS (внешний вид) и JavaScript (поведение) при создании современных сайтов.

Без HTML невозможно отобразить веб-страницу в браузере, так как именно он задаёт каркас, к которому применяются стили и скрипты.

## Пример

Простейшая HTML-страница:

```html
<!DOCTYPE html>
<html lang='ru'>
<head>
    <meta charset='UTF-8'>
    <title>Пример страницы</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Это простой пример HTML-документа.</p>
    <a href='https://example.com'>Ссылка на пример</a>
</body>
</html>
```

В этом примере `<!DOCTYPE html>` объявляет тип документа, тег `<html>` является корневым, `<head>` содержит метаданные, а `<body>` — видимое содержимое страницы.
