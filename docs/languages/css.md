# CSS

## Определение
CSS (Cascading Style Sheets) — это язык таблиц стилей, который используется для описания внешнего вида и форматирования документов, написанных на языках разметки, таких как HTML или XML. Он определяет, как элементы должны отображаться на экране, на бумаге, в речи или других медиа.

## Зачем нужно
CSS позволяет отделить содержимое документа (HTML) от его визуального представления. Это упрощает поддержку сайтов, обеспечивает единообразие дизайна, ускоряет загрузку страниц за счёт кэширования стилей и делает вёрстку адаптивной для разных устройств. Без CSS веб-страницы выглядели бы как простой неформатированный текст.

## Пример
Ниже приведён простой пример CSS, который задаёт цвет текста, шрифт, выравнивание и отступы для заголовка и абзаца:

```css
/* Стили для заголовка */
h1 {
  color: #2c3e50;
  font-family: Arial, sans-serif;
  text-align: center;
}

/* Стили для абзаца */
p {
  color: #34495e;
  line-height: 1.6;
  margin: 16px;
}
```

Этот CSS можно подключить к HTML-документу следующим образом:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Пример CSS</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это пример использования CSS для оформления веб-страницы.</p>
</body>
</html>
```
