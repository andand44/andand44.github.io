# CSS

## Определение
CSS (Cascading Style Sheets — каскадные таблицы стилей) — это язык таблиц стилей, который используется для описания внешнего вида и форматирования документов, написанных на языках разметки, таких как HTML или XML. CSS определяет цвета, шрифты, отступы, расположение элементов и другие визуальные параметры, отделяя содержимое страницы от её представления.

## Зачем нужно
- **Разделение структуры и оформления**: HTML отвечает за смысловую структуру документа, а CSS — за его визуальное отображение.
- **Централизованное управление стилем**: можно подключить один файл стилей ко многим страницам и быстро изменить дизайн всего сайта.
- **Адаптивность и кроссбраузерность**: медиазапросы позволяют адаптировать интерфейс под разные размеры экранов и устройства.
- **Повышение производительности и доступности**: грамотное использование CSS уменьшает дублирование кода и улучшает восприятие контента.
- **Гибкость и анимации**: современный CSS поддерживает переходы, трансформации и анимации без использования JavaScript.

## Пример
Ниже приведён простой пример CSS-файла `styles.css`, который задаёт базовое оформление страницы:

```css
/* Базовые стили для тела документа */
body {
  margin: 0;
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
  background-color: #f9f9fb;
  color: #222;
}

/* Стили для заголовка первого уровня */
h1 {
  color: #1e6f5c;
  text-align: center;
  padding: 24px 16px;
}

/* Стили для абзацев */
p {
  line-height: 1.6;
  max-width: 760px;
  margin: 0 auto 16px;
  padding: 0 16px;
}

/* Адаптивность: уменьшаем заголовок на узких экранах */
@media (max-width: 600px) {
  h1 {
    font-size: 1.6rem;
  }
}
```

Пример HTML-документа, использующего этот CSS:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Пример использования CSS</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <h1>Добро пожаловать!</h1>
  <p>Это демонстрационная страница, оформленная с помощью каскадных таблиц стилей.</p>
</body>
</html>
```
