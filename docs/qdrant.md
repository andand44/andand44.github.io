## Qdrant

### Определение

**Qdrant** — это открытая векторная база данных (vector database), предназначенная для хранения векторных представлений данных и выполнения высокопроизводительного поиска по сходству (similarity search). Написана на Rust, что обеспечивает высокую скорость и надёжность. Qdrant поддерживает векторы, полезную нагрузку (payload) и расширенную фильтрацию, что делает её полноценной платформой для production-систем в области машинного обучения и искусственного интеллекта.

### Зачем нужно

Qdrant решает задачу поиска информации не по точным ключевым словам, а по семантическому смыслу. Она используется там, где нужно быстро находить объекты, близкие к заданному запросу в многомерном пространстве:

- **RAG (Retrieval-Augmented Generation)** — поиск релевантных фрагментов для ответов языковой модели.
- **Семантический поиск** — поиск по смыслу в текстах, изображениях, аудио, видео.
- **Рекомендательные системы** — подбор похожих товаров, статей, фильмов или пользователей.
- **Поиск аномалий** — нахождение выбросов по близости к кластерам.
- **Deduplication** — обнаружение дубликатов и похожих документов.

Ключевые возможности:

- Быстрый поиск по метрикам расстояния: косинус, евклидово расстояние, скалярное произведение.
- Фильтрация по метаданным (payload) перед поиском или параллельно с ним.
- Поддержка индексов (HNSW) для эффективного поиска в больших коллекциях.
- Простой управляемый API, клиенты для Python, TypeScript, Go, Rust.
- Имеет облачный сервис Qdrant Cloud и вариант для self-hosting.

### Пример использования

Допустим, у нас есть коллекция описаний товаров, и мы хотим находить похожие товары по запросу. Предварительно каждое описание переведено в эмбеддинг (например, через OpenAI или sentence-transformers).

```python
from qdrant_client import QdrantClient
from qdrant_client.models import PointStruct, VectorParams, Distance

# Подключаемся к Qdrant
client = QdrantClient(host="localhost", port=6333)

# Создаём коллекцию dimension = 768 (размерность эмбеддингов)
client.recreate_collection(
    collection_name="products",
    vectors_config=VectorParams(size=768, distance=Distance.COSINE),
)

# Вектор товара (гипотетический) и метаданные
vectors = [
    PointStruct(
        id=1,
        vector=[0.12, 0.34, ...],  # эмбеддинг описания "умный фитнес-браслет"
        payload={"title": "Умный браслет", "category": "electronics"}
    ),
    PointStruct(
        id=2,
        vector=[0.98, 0.12, ...],  # эмбеддинг описания "кожаный ремешок"
        payload={"title": "Ремешок", "category": "accessories"}
    ),
]

# Загружаем данные
client.upsert(collection_name="products", points=vectors)

# Вектор запроса "спортивный гаджет" — получаем похожие товары
query_vector = [0.20, 0.55, ...]

results = client.search(
    collection_name="products",
    query_vector=query_vector,
    limit=5,
    query_filter=None,  # здесь можно указать фильтр, например, category="electronics"
)

for hit in results:
    print(hit.payload["title"], hit.score)
```

Этот код создаёт коллекцию, добавляет объекты с векторами и payload, а затем находит самые близкие продукты к запросу по косинусной близости.
