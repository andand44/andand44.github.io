# Regex

## Определение

Регулярные выражения (Regex) — это формальный язык для поиска и манипуляции подстроками в тексте на основе шаблонов. Они позволяют описывать набор строк, которые соответствуют заданному образцу, используя метасимволы, квантификаторы и группы.

## Зачем нужно

Regex используется для валидации данных (email, телефон, URL), поиска и замены текста, парсинга логов, извлечения информации, подсветки синтаксиса и во многих других задачах автоматизации. Это мощный инструмент, который экономит время и упрощает работу с текстом практически в любом языке программирования.

## Пример

Пример на Python: найти все email-адреса в строке.

```python
import re

text = "Свяжитесь с нами: support@example.com или sales@example.org"
pattern = r"[\w.+-]+@[\w-]+\.[\w.]+"

emails = re.findall(pattern, text)
print(emails)
# ['support@example.com', 'sales@example.org']
```

Здесь шаблон описывает типичную структуру email: латинские буквы, цифры и некоторые символы до @, затем домен и доменную зону.
