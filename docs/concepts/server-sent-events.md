# Server-Sent Events

## Определение
Server-Sent Events (SSE) — это технология, позволяющая серверу отправлять асинхронные обновления клиенту (например, веб-браузеру) по протоколу HTTP. Она обеспечивает одностороннюю связь (только от сервера к клиенту) в реальном времени. В отличие от WebSockets, SSE работает поверх стандартного HTTP/HTTPS, что упрощает её интеграцию и позволяет использовать существующую сетевую инфраструктуру без дополнительных настроек.

## Зачем нужно
SSE идеально подходит для приложений, которым требуется получать поток данных в реальном времени, но не нужно отправлять данные обратно на сервер по тому же соединению. Основные сценарии использования:
- **Уведомления:** мгновенная доставка уведомлений о новых сообщениях, лайках или системных событиях.
- **Стриминг данных:** трансляция курсов валют, котировок акций, спортивных счетов или обновлений в социальных сетях.
- **Мониторинг состояния:** отображение прогресса длительных процессов на сервере (например, обработка видео, генерация отчетов).
- **Логирование:** вывод логов сервера в реальном времени прямо в браузере.

Ключевые преимущества SSE включают нативную поддержку в браузерах (через API `EventSource`), автоматическое переподключение при разрыве соединения и поддержку HTTP/2.

## Пример
Рассмотрим базовый пример реализации SSE на клиенте (JavaScript) и сервере (Node.js с фреймворком Express).

### Клиент (JavaScript)
```javascript
// Подключаемся к серверному маршруту /events
const eventSource = new EventSource('/events');

// Обработчик входящих сообщений
eventSource.onmessage = function(event) {
    console.log('Новое сообщение от сервера:', event.data);
};

// Обработчик ошибок и закрытия соединения
eventSource.onerror = function(error) {
    console.error('Ошибка соединения SSE:', error);
};
```

### Сервер (Node.js / Express)
```javascript
const express = require('express');
const app = express();

app.get('/events', (req, res) => {
    // Устанавливаем заголовки, необходимые для SSE
    res.setHeader('Content-Type', 'text/event-stream');
    res.setHeader('Cache-Control', 'no-cache');
    res.setHeader('Connection', 'keep-alive');
    
    let counter = 0;
    
    // Отправляем данные клиенту каждые 2 секунды
    const intervalId = setInterval(() => {
        counter++;
        // Формат данных: "data: <полезная нагрузка>\n\n"
        res.write(`data: Текущее время: ${new Date().toISOString()} (сообщение №${counter})\n\n`);
    }, 2000);

    // Завершаем интервал при отключении клиента
    req.on('close', () => {
        clearInterval(intervalId);
        res.end();
    });
});

app.listen(3000, () => {
    console.log('SSE сервер запущен на порту 3000');
});
```
