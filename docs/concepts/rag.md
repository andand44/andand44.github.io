# RAG

## Определение
RAG (Retrieval-Augmented Generation) — это архитектурный подход в области искусственного интеллекта, который улучшает качество ответов больших языковых моделей (LLM) путем интеграции с внешними источниками знаний. Вместо того чтобы полагаться исключительно на данные, полученные в ходе предварительного обучения, модель сначала извлекает (retrieval) релевантную информацию из внешней базы данных или документации, а затем использует этот контекст для генерации (generation) точного и обоснованного ответа.

## Зачем нужно
Внедрение RAG решает несколько фундаментальных проблем стандартных LLM:
1. **Актуальность данных:** Базовые модели знают только то, на чем они обучались до определенной даты. RAG позволяет использовать информацию в реальном времени.
2. **Снижение галлюцинаций:** Поскольку ответ генерируется на основе фактических извлеченных данных, модель реже выдумывает несуществующие факты.
3. **Работа с приватной информацией:** RAG позволяет компаниям создавать ИИ-ассистентов, которые отвечают на вопросы на основе закрытой внутренней документации, без необходимости дорогостоящего переобучения (fine-tuning) самой языковой модели.
4. **Прозрачность:** Система может предоставлять ссылки на источники, из которых была взята информация, что позволяет пользователям проверять достоверность ответа.

## Пример
Представьте, что вы разрабатываете чат-бота для службы поддержки интернет-магазина.

**Запрос пользователя:** *Где мой заказ, который я сделал вчера?*

**Работа системы с RAG:**
1. **Извлечение (Retrieval):** Система анализирует запрос и ищет информацию о заказах этого пользователя во внутренней базе данных магазина. Она находит запись: *Заказ №456 передан в службу доставки, ожидается завтра*.
2. **Генерация (Generation):** Извлеченная информация передается в LLM вместе с исходным вопросом. Модель формирует человекочитаемый ответ: *Ваш заказ №456 уже передан в службу доставки и будет доставлен завтра. Благодарим за покупку!*

Без использования RAG языковая модель не имела бы доступа к базе данных магазина и не смогла бы ответить на этот вопрос.
