# RAG

### Определение

RAG (Retrieval-Augmented Generation — генерация, дополненная поиском) — это архитектурный подход в области искусственного интеллекта, который расширяет возможности больших языковых моделей (LLM), объединяя их с внешними системами поиска информации. Вместо того чтобы генерировать ответ исключительно на основе своих внутренних параметров (полученных в процессе обучения), модель сначала извлекает релевантные данные из внешней базы знаний, а затем использует этот контекст для формирования точного и обоснованного ответа.

### Зачем нужно

Использование RAG решает ряд фундаментальных проблем стандартных языковых моделей:

1. **Устаревание знаний:** Базовые модели ограничены данными, на которых они были обучены. RAG позволяет подтягивать самую актуальную информацию в реальном времени.
2. **Галлюцинации:** Когда модель опирается на извлеченные факты, она реже выдумывает несуществующие события, ссылки или детали.
3. **Работа с приватными данными:** Компании могут безопасно подключить свои внутренние базы знаний, документацию или корпоративные данные без необходимости проводить дорогостоящее дообучение (fine-tuning) самой модели.
4. **Прозрачность и проверяемость:** Система может указывать конкретные источники, из которых была взята информация, что делает ответы прозрачными и повышает доверие пользователей.

### Пример

Рассмотрим работу интеллектуального чат-бота технической поддержки интернет-магазина.

**Запрос пользователя:** *«Как изменить адрес доставки уже оплаченного заказа?»*

**Как это работает с RAG:**
1. **Поиск (Retrieval):** Система получает запрос и ищет по внутренней базе знаний магазина (например, в векторной базе данных) разделы, касающиеся изменения адреса доставки.
2. **Дополнение (Augmentation):** Найденный фрагмент инструкции (например: *«Адрес можно изменить в течение 2 часов после оплаты в личном кабинете»*) добавляется к исходному запросу пользователя в качестве контекста.
3. **Генерация (Generation):** LLM получает и сам запрос, и найденный контекст, после чего формулирует вежливый и точный ответ: *«Вы можете изменить адрес доставки в личном кабинете, но только в течение 2 часов после оплаты заказа».*
