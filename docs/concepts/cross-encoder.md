# Cross-Encoder

## Определение

**Cross-Encoder** (кросс-энкодер) — это архитектура нейронных сетей (обычно на базе Transformer, например, BERT), используемая в обработке естественного языка (NLP) для оценки семантической близости или релевантности двух текстов.

В отличие от Bi-Encoder (двухбашенной модели), который преобразует тексты в векторы независимо друг от друга, Cross-Encoder принимает на вход **пару текстов одновременно** (например, поисковый запрос и документ), объединяет их в одну последовательность (обычно через специальный токен `[SEP]`) и пропускает через модель. На выходе модель выдает одно числовое значение (скор), указывающее на степень их соответствия.

## Зачем нужно

Cross-Encoder используется там, где требуется **максимальная точность** сравнения текстов.

Поскольку оба текста обрабатываются совместно, механизм self-attention (внимания) может анализировать слова из первого текста в контексте второго. Это позволяет улавливать тончайшие смысловые связи и нюансы, что делает Cross-Encoder значительно точнее Bi-Encoder.

Однако у этой точности есть цена — **вычислительная сложность**. Нельзя заранее вычислить эмбеддинги для всех документов в базе, так как модель должна обрабатывать каждую пару "запрос-документ" заново. Поэтому Cross-Encoder не применяется для первичного поиска по миллионам записей. Вместо этого он используется на этапе **реранжирования (re-ranking)**: сначала быстрый алгоритм (например, BM25 или Bi-Encoder) находит топ-N подходящих документов, а затем Cross-Encoder тщательно оценивает и пересортировывает их, чтобы выдать самые релевантные результаты наверх.

## Пример

Рассмотрим пример использования Cross-Encoder для ранжирования документов с помощью популярной библиотеки `sentence-transformers` на Python.

```python
from sentence_transformers import CrossEncoder

# 1. Загружаем предобученную модель Cross-Encoder
model = CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2')

# 2. Формируем пары: (Запрос, Документ)
query = "Сколько людей живет в Берлине?"
documents = [
    "В Берлине проживает около 3,5 миллионов человек.",
    "Берлин известен своей богатой историей и культурой.",
    "Яблоки полезны для здоровья."
]

pairs = [[query, doc] for doc in documents]

# 3. Получаем оценки релевантности для каждой пары
scores = model.predict(pairs)

# 4. Выводим результаты
for doc, score in zip(documents, scores):
    print(f"Оценка: {score:.4f} | Документ: {doc}")

# Ожидаемый результат (чем выше оценка, тем лучше):
# Оценка: 8.1234 | Документ: В Берлине проживает около 3,5 миллионов человек.
# Оценка: 2.5678 | Документ: Берлин известен своей богатой историей и культурой.
# Оценка: -5.4321 | Документ: Яблоки полезны для здоровья.
```
