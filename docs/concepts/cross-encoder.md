# Cross-Encoder

## Определение

**Cross-Encoder** (кросс-энкодер) — это архитектура нейронной сети (обычно на базе Transformer, например, BERT), предназначенная для совместной обработки и оценки пары текстов. В отличие от Bi-Encoder, который создает независимые векторные представления (эмбеддинги) для каждого текста по отдельности, Cross-Encoder принимает оба текста одновременно (объединяя их в одну последовательность, часто через токен-разделитель `[SEP]`). Модель пропускает эту объединенную последовательность через себя и на выходе выдает единую оценку (скор), отражающую семантическую близость, релевантность или логическую связь между входными данными.

## Зачем нужно

Главная причина использования Cross-Encoder — **высокая точность**. Поскольку модель обрабатывает оба текста вместе, механизм внимания (self-attention) может анализировать взаимосвязи между каждым словом первого текста и каждым словом второго. Это позволяет улавливать тончайшие смысловые нюансы, которые теряются при независимом кодировании.

Основные сценарии применения:
1. **Рерanking (переранжирование) в поисковых системах:** Сначала быстрый алгоритм (например, BM25 или векторный поиск) извлекает топ-N подходящих документов. Затем Cross-Encoder последовательно оценивает каждый из этих документов в паре с поисковым запросом, чтобы точно определить самые релевантные и поднять их наверх.
2. **Семантическое сходство:** Точное определение того, являются ли два предложения парафразами или дубликатами.
3. **Question Answering (ответы на вопросы):** Оценка того, насколько точно тот или иной фрагмент текста отвечает на заданный вопрос.

*Недостаток:* Cross-Encoder работает значительно медленнее, так как требует парной обработки в реальном времени. Невозможно заранее вычислить и сохранить эмбеддинги документов в базу данных, поэтому его применяют только для небольшого пула кандидатов.

## Пример

Представим задачу информационного поиска. У нас есть запрос: *"Какая столица Франции?"* и два документа-кандидата:
1. *"Франция — страна в Западной Европе."*
2. *"Париж является столицей и самым густонаселенным городом Франции."*

Мы подаем в Cross-Encoder пары `[Запрос, Документ]` и получаем оценки релевантности. 

Пример реализации на Python с использованием библиотеки `sentence-transformers`:

```python
from sentence_transformers import CrossEncoder

# Инициализация предобученной модели
model = CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2')

query = "Какая столица Франции?"
docs = [
    "Франция — страна в Западной Европе.",
    "Париж является столицей и самым густонаселенным городом Франции."
]

# Формируем пары для модели
pairs = [[query, doc] for doc in docs]

# Получаем оценки (чем выше score, тем выше релевантность)
scores = model.predict(pairs)

for doc, score in zip(docs, scores):
    print(f"Документ: {doc} | Оценка: {score:.4f}")

# Примерный вывод:
# Документ: Франция — страна в Западной Европе. | Оценка: -2.1543
# Документ: Париж является столицей и самым густонаселенным городом Франции. | Оценка: 8.8921
```

Как видно из примера, модель присвоила второму документу гораздо более высокий балл, так как он напрямую отвечает на запрос.
