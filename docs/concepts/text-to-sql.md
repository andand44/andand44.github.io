# Text-to-SQL

### Определение

**Text-to-SQL** (или NL-to-SQL) — это технология и задача в области обработки естественного языка (NLP), которая заключается в автоматическом преобразовании запросов на естественном человеческом языке в структурированные SQL-запросы, понятные реляционным базам данных. Современные решения часто строятся на базе больших языковых моделей (LLM).

### Зачем нужно

1. **Демократизация данных:** Позволяет сотрудникам без технических навыков (менеджерам, маркетологам, аналитикам) получать данные из базы, не зная синтаксиса SQL.
2. **Ускорение работы:** Специалисты по данным могут быстрее писать сложные запросы, используя генерацию черновиков на естественном языке.
3. **Снижение нагрузки на разработчиков:** Отпадает необходимость постоянно отвлекать дата-инженеров для создания простых выгрузок и отчетов.
4. **Улучшение бизнес-аналитики (BI):** Упрощает взаимодействие с корпоративными хранилищами данных через чат-ботов и голосовых помощников.

### Пример

Представим базу данных интернет-магазина с таблицей `orders` (поля: `id`, `customer_id`, `order_date`, `total_amount`, `status`).

**Ввод (естественный язык):**
> "Покажи общую сумму всех доставленных заказов за последний месяц."

**Вывод (SQL-запрос):**
```sql
SELECT SUM(total_amount) 
FROM orders 
WHERE status = 'delivered' 
  AND order_date >= DATE('now', '-1 month');
```

*(Примечание: конкретный синтаксис функций работы с датами может зависеть от используемой СУБД, например, PostgreSQL, MySQL и т.д.)*
