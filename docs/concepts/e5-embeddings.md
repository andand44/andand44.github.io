# E5 embeddings

## Определение

**E5 embeddings** (от англ. *EmbEddings from bidirEctional Encoder rEpresentations*) — это семейство моделей машинного обучения для получения векторных представлений текста. Модели E5 были разработаны компанией Microsoft и используют архитектуру трансформеров с двунаправленным кодированием. Основная задача E5 — преобразовывать предложения, абзацы или документы в плотные векторы фиксированной размерности, которые сохраняют семантический смысл текста. Эти векторы позволяют находить похожие по смыслу тексты с помощью мер косинусной близости или других метрик расстояния.

## Зачем нужно

E5 embeddings применяются в задачах семантического поиска, кластеризации текстов, классификации, рекомендательных системах и построении вопросно-ответных систем. По сравнению с классическими подходами (например, TF-IDF или word2vec) E5 учитывают контекст слова, что позволяет улавливать тонкие смысловые оттенки, синонимы и сложные языковые конструкции. Модели E5 доступны в нескольких вариантах, включая мультиязычные, что даёт возможность работать с текстами на разных языках без потери качества. Благодаря предобученности на больших корпусах текстов, их можно использовать «как есть» или дообучать под конкретную предметную область, достигая высокой точности при минимальном количестве размеченных данных.

## Пример

Ниже приведён пример использования E5 embeddings через библиотеку `sentence-transformers` для получения векторов и вычисления семантической близости.

```python
from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity

# Загружаем предобученную модель E5 (мультиязычная версия)
model = SentenceTransformer('intfloat/multilingual-e5-base')

# Тексты для сравнения
texts = [
    "Как работает алгоритм градиентного бустинга?",
    "Что такое машинное обучение?",
    "Рецепт вкусного борща"
]

# Кодируем тексты в эмбеддинги (к каждому запросу добавляем префикс 'query:' или 'passage:')
embeddings = model.encode(["query: " + t for t in texts])

# Считаем косинусную близость между первым текстом и остальными
scores = cosine_similarity([embeddings[0]], embeddings[1:])[0]

print(f"Сходство с текстом 1: {scores[0]:.4f}")
print(f"Сходство с текстом 2: {scores[1]:.4f}")
```

Результат покажет, что первый текст семантически ближе ко второму (машинное обучение), чем к третьему (кулинария).
