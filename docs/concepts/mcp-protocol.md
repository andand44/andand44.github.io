# MCP Protocol

## Определение

**MCP Protocol** (Model Context Protocol) — открытый протокол и стандарт, предложенный Anthropic, который определяет, как LLM-приложения (клиенты) подключаются к внешним источникам данных и инструментам через единый интерфейс. Обмен сообщениями строится на базе JSON-RPC 2.0 и может работать поверх stdio или HTTP/SSE. Протокол описывает сущности `resources`, `prompts`, `tools` и `sampling`, позволяя модели безопасно получать контекст, читать файлы, обращаться к базам данных и вызывать функции.

## Зачем нужно

- **Устранение проблемы N×M**: без стандарта каждая модель или приложение требует отдельной интеграции с каждым сервисом. MCP вводит единый слой совместимости.
- **Безопасность и контроль**: MCP-сервер сам решает, какие данные и инструменты предоставить клиенту, не раскрывая всю систему модели.
- **Переиспользование**: один сервер (например, для PostgreSQL, GitHub или файловой системы) можно подключить к разным LLM-клиентам.
- **Улучшение агентов и RAG**: модель получает актуальный контекст и может выполнять действия через инструменты, а не только генерировать текст.
- **Гибкость**: поддерживаются локальные и удалённые источники, стриминг ответов и уведомления об изменениях.

## Пример

Минимальный MCP-сервер на Python с использованием официального SDK:

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP('demo')

@mcp.tool()
def get_weather(city: str) -> str:
    '''Возвращает фиктивную погоду для города.'''
    return f'В городе {city} сейчас солнечно, +25°C'

if __name__ == '__main__':
    mcp.run()
```

Клиент с поддержкой MCP (например, Claude Desktop или IDE) подключает сервер через конфигурацию:

```json
{
  "mcpServers": {
    "weather": {
      "command": "python",
      "args": ["weather_server.py"]
    }
  }
}
```

После подключения модель может вызвать инструмент. Упрощённый обмен по JSON-RPC выглядит так:

Запрос:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get_weather",
    "arguments": { "city": "Москва" }
  }
}
```

Ответ:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [
      { "type": "text", "text": "В городе Москва сейчас солнечно, +25°C" }
    ]
  }
}
```

В результате LLM получает структурированный ответ и может использовать его для формирования ответа пользователю.
