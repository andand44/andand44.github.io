# Uvicorn

### Определение
**Uvicorn** — это легковесный и высокопроизводительный ASGI-сервер (Asynchronous Server Gateway Interface) для Python. Он построен на базе `uvloop` и `httptools`, что делает его одним из самых быстрых решений для запуска асинхронных веб-приложений. Uvicorn выступает в роли интерфейса между клиентом и асинхронными фреймворками, такими как FastAPI или Starlette.

### Зачем нужно
Uvicorn решает проблему обработки асинхронных операций в Python. Классические WSGI-серверы (например, Gunicorn по умолчанию) работают синхронно и блокируют поток при ожидании ввода-вывода, что плохо масштабируется при большом количестве одновременных соединений.

Основные причины использования Uvicorn:
- **Асинхронность:** Полная поддержка конструкций `async/await` и стандарта ASGI.
- **Производительность:** Использование `uvloop` (обертка над библиотекой libuv, написанной на C) значительно ускоряет обработку событий по сравнению со стандартным `asyncio`.
- **WebSockets:** Нативная и эффективная поддержка протокола WebSocket для приложений реального времени.

### Пример
Установка Uvicorn с рекомендуемыми зависимостями для повышения производительности:

```bash
pip install "uvicorn[standard]"
```

Создание простого ASGI-приложения в файле `main.py`:

```python
async def app(scope, receive, send):
    assert scope['type'] == 'http'
    
    await send({
        'type': 'http.response.start',
        'status': 200,
        'headers': [
            [b'content-type', b'text/plain'],
        ],
    })
    await send({
        'type': 'http.response.body',
        'body': b'Hello, Uvicorn!',
    })
```

Запуск сервера через терминал:

```bash
uvicorn main:app --reload
```

После выполнения команды сервер запустится на `http://127.0.0.1:8000`, а параметр `--reload` обеспечит автоматическую перезагрузку при изменении кода во время разработки.
