# Uvicorn

## Определение
Uvicorn — это легковесный и высокопроизводительный ASGI (Asynchronous Server Gateway Interface) веб-сервер для Python. Он построен на основе библиотек `uvloop` и `httptools` и предназначен для запуска современных асинхронных веб-приложений и фреймворков (таких как FastAPI и Starlette).

## Зачем нужно
Традиционные WSGI-серверы (например, Gunicorn в синхронном режиме) не поддерживают асинхронность, что ограничивает производительность при обработке большого количества одновременных соединений (например, WebSockets или long-polling). Uvicorn решает эту проблему, реализуя стандарт ASGI. Это позволяет разработчикам в полной мере использовать возможности `async/await` в Python, обеспечивая высокую скорость обработки запросов, низкое потребление ресурсов и возможность легкого масштабирования высоконагруженных микросервисов.

## Пример
Рассмотрим запуск простого приложения на базе фреймворка FastAPI с помощью Uvicorn.

1. Установка необходимых библиотек:
```bash
pip install fastapi uvicorn
```

2. Создание файла `main.py`:
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def read_root():
    return {"message": "Hello from Uvicorn!"}
```

3. Запуск сервера через терминал:
```bash
uvicorn main:app --reload
```
После выполнения команды Uvicorn запустит сервер (по умолчанию на `127.0.0.1:8000`). Параметр `--reload` позволяет серверу автоматически перезапускаться при изменении кода в файле `main.py`, что очень удобно в процессе разработки.
