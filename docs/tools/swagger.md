# Swagger

## Определение
**Swagger** — это набор инструментов с открытым исходным кодом, созданных для проектирования, разработки, документирования и тестирования RESTful API. В основе Swagger лежит спецификация OpenAPI (ранее известная как Swagger Specification). Он предоставляет стандартизированный, машиночитаемый формат для описания структуры API, что делает его понятным как для разработчиков, так и для автоматизированных систем.

## Зачем нужно
Swagger решает несколько ключевых задач при работе с API:
1. **Автоматическая документация:** Swagger автоматически генерирует интерактивную документацию на основе кода или файла конфигурации. Это избавляет разработчиков от необходимости писать и обновлять документацию вручную.
2. **Упрощение тестирования:** Интерфейс Swagger UI позволяет отправлять запросы к API прямо из браузера, что значительно упрощает процесс отладки и тестирования эндпоинтов.
3. **Генерация кода (Codegen):** Инструменты Swagger могут автоматически генерировать серверные заглушки (stubs) и клиентские библиотеки (SDK) на множестве языков программирования на основе спецификации API.
4. **Стандартизация и коммуникация:** Использование единого формата описания API улучшает взаимодействие между командами (например, фронтенда и бэкенда) и упрощает интеграцию со сторонними сервисами.

## Пример
Ниже приведен простой пример спецификации OpenAPI (в формате YAML), которая описывает один эндпоинт для получения списка пользователей:

```yaml
openapi: 3.0.0
info:
  title: Пример API пользователей
  version: 1.0.0
paths:
  /users:
    get:
      summary: Получить список пользователей
      responses:
        '200':
          description: Успешный запрос
          content:
            application/json:
              schema:
                type: array
                items:
                  type: object
                  properties:
                    id:
                      type: integer
                      example: 1
                    name:
                      type: string
                      example: Иван Иванов
```

В экосистеме Swagger этот файл можно загрузить в **Swagger Editor** для просмотра и редактирования, а затем отобразить в виде интерактивной веб-страницы с помощью **Swagger UI**, где можно будет нажать кнопку "Try it out" и выполнить реальный запрос к серверу.
