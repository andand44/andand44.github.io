# Swagger

## Определение

**Swagger** — это набор инструментов с открытым исходным кодом для проектирования, разработки, документирования и тестирования RESTful API. В основе экосистемы Swagger лежит спецификация OpenAPI (ранее известная как Swagger Specification) — стандартизированный формат (YAML или JSON) для описания структуры веб-API.

## Зачем нужно

Использование Swagger значительно упрощает жизненный цикл разработки API и решает несколько ключевых задач:

* **Автоматическая документация:** Инструмент Swagger UI генерирует интерактивную, наглядную и всегда актуальную документацию на основе файла спецификации.
* **Подход API-First (Сначала API):** Позволяет командам сначала создать и согласовать контракт API, а затем приступать к параллельной разработке бэкенда и фронтенда.
* **Генерация кода:** С помощью Swagger Codegen можно автоматически создавать серверные заглушки (stubs) и клиентские библиотеки (SDK) для множества языков программирования.
* **Удобство тестирования:** Благодаря интерактивности документации, разработчики могут отправлять запросы к API прямо из браузера, что ускоряет отладку.

## Пример

Ниже приведен пример файла спецификации OpenAPI (в формате YAML), который используется инструментами Swagger для генерации документации:

```yaml
openapi: 3.0.0
info:
  title: API пользователей
  version: 1.0.0
paths:
  /users/{id}:
    get:
      summary: Получение информации о пользователе
      parameters:
        - name: id
          in: path
          required: true
          description: Уникальный идентификатор пользователя
          schema:
            type: integer
      responses:
        '200':
          description: Пользователь успешно найден
          content:
            application/json:
              schema:
                type: object
                properties:
                  id:
                    type: integer
                  username:
                    type: string
        '404':
          description: Пользователь не найден
```

В этом примере описывается эндпоинт `GET /users/{id}`. Если загрузить этот файл в Swagger Editor или Swagger UI, сгенерируется веб-интерфейс, где будет указано описание метода, параметры, возможные ответы, а также появится кнопка для немедленного выполнения тестового запроса.
