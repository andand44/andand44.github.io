# Google Sheets

## Определение

Google Sheets — это облачное приложение для работы с электронными таблицами, входящее в состав Google Workspace (ранее G Suite). Оно позволяет создавать, редактировать и совместно использовать таблицы в браузере или через мобильные приложения, а также автоматизировать работу с помощью формул, сводных таблиц, диаграмм и Google Apps Script.

## Зачем нужно

- **Совместная работа в реальном времени**: несколько пользователей могут одновременно редактировать таблицу, видеть изменения и оставлять комментарии.
- **Доступ из любой точки**: данные хранятся в облаке, поэтому работать можно с любого устройства без установки ПО.
- **Автоматизация и интеграция**: формулы, макросы, Google Apps Script и готовые коннекторы (например, через Google Forms, BigQuery, Looker Studio) позволяют строить отчёты, собирать данные и связывать Sheets с другими сервисами.
- **Простой анализ данных**: функции, фильтры, сводные таблицы и диаграммы помогают быстро анализировать информацию без сложных инструментов.
- **Бесплатный старт**: для частных лиц есть бесплатная версия с достаточным функционалом для большинства повседневных задач.

## Пример

Допустим, в диапазоне `A1:A10` находятся числа. Чтобы посчитать их сумму, среднее значение и найти максимальное число, можно использовать формулы:

```excel
=SUM(A1:A10)
=AVERAGE(A1:A10)
=MAX(A1:A10)
```

Пример таблицы:

| Товар   | Цена | Количество | Итого |
|---------|------|------------|-------|
| Яблоки  | 50   | 10         | `=B2*C2` |
| Груши   | 70   | 5          | `=B3*C3` |
| Сливы   | 60   | 8          | `=B4*C4` |

В ячейке `D5` можно подсчитать общую сумму:

```excel
=SUM(D2:D4)
```

Если нужно автоматически отправлять отчёт по почте, можно использовать Google Apps Script:

```javascript
function sendReport() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const total = sheet.getRange('D5').getValue();
  MailApp.sendEmail('user@example.com', 'Отчёт по продажам', 'Итого: ' + total);
}
```
