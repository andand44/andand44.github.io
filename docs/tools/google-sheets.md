# Google Sheets

### Определение

Google Sheets (Google Таблицы) — это облачное приложение для работы с электронными таблицами, разработанное компанией Google. Оно входит в пакет Google Workspace и позволяет пользователям создавать, редактировать и анализировать табличные данные через веб-браузер или мобильное приложение.

### Зачем нужно

Google Sheets применяется для решения широкого круга задач:

- **Совместная работа:** Множество пользователей могут одновременно редактировать один файл, видеть изменения в реальном времени, оставлять комментарии и вести историю версий.
- **Обработка и анализ данных:** Инструмент поддерживает сложные формулы, сводные таблицы, условное форматирование и построение диаграмм.
- **Автоматизация:** Благодаря интеграции с Google Apps Script (на базе JavaScript) можно автоматизировать рутинные задачи, создавать пользовательские меню и функции.
- **Хранение и обмен:** Удобен для ведения простых баз данных, списков и трекеров задач с возможностью легкого предоставления доступа по ссылке.

### Пример

Пример использования формулы для вычисления суммы значений в диапазоне ячеек от A1 до A10:

```excel
=SUM(A1:A10)
```

Пример скрипта на Google Apps Script, который отправляет электронное письмо на адрес, указанный в ячейке B2:

```javascript
function sendCustomEmail() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var emailAddress = sheet.getRange('B2').getValue();
  var subject = 'Отчет из Google Таблиц';
  var message = 'Здравствуйте! Данные были успешно обновлены.';
  
  MailApp.sendEmail(emailAddress, subject, message);
}
```
