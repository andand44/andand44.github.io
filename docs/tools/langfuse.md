# Langfuse

### Определение

Langfuse — это платформа с открытым исходным кодом для LLMOps (инженерии больших языковых моделей), которая предоставляет инструменты для трассировки, мониторинга, оценки и отладки приложений на базе LLM. Она легко интегрируется с популярными фреймворками (например, LangChain, LlamaIndex) и позволяет разработчикам получить полную прозрачность работы их ИИ-агентов.

### Зачем нужно

Разработка приложений на базе LLM часто сталкивается с проблемой «черного ящика»: сложно понять, почему модель выдала определенный ответ, сколько токенов было потрачено и на каком этапе произошел сбой. Langfuse необходим для решения следующих задач:

1. **Трассировка (Tracing):** Детальная визуализация всех шагов выполнения запроса (промпты, ответы, вызовы внешних API и баз данных) в виде удобного дерева.
2. **Мониторинг:** Отслеживание метрик производительности, таких как задержка (latency), стоимость запросов и количество ошибок в реальном времени.
3. **Оценка качества (Evaluation):** Сбор обратной связи от пользователей (лайки/дислайки) и автоматическая оценка ответов с помощью других LLM для контроля деградации модели.
4. **Управление промптами:** Централизованное хранение, версионирование и тестирование промптов без изменения кода приложения.

### Пример

Пример интеграции Langfuse в Python-приложение с использованием декоратора `@observe()` для отслеживания вызова модели OpenAI:

```python
import os
from langfuse.decorators import observe, langfuse_context
from openai import OpenAI

# Настройка ключей Langfuse (рекомендуется через переменные окружения)
os.environ["LANGFUSE_SECRET_KEY"] = "sk-lf-..."
os.environ["LANGFUSE_PUBLIC_KEY"] = "pk-lf-..."

client = OpenAI()

@observe() # Декоратор для трассировки выполнения функции
def translate_text(text, target_language):
    # Добавление пользовательских метаданных
    langfuse_context.update_current_trace(
        name="TranslateText",
        metadata={"target_language": target_language}
    )
    
    # Вызов LLM
    response = client.chat.completions.create(
        model="gpt-4",
        messages=[
            {"role": "system", "content": "Ты профессиональный переводчик."},
            {"role": "user", "content": f"Переведи текст на {target_language}: {text}"}
        ]
    )
    
    return response.choices[0].message.content

# Вызов функции
translated = translate_text("Hello, world!", "русский")
print(translated)

# Отправка собранных данных в дашборд Langfuse
langfuse_context.flush()
```

В результате выполнения этого кода в интерфейсе Langfuse появится подробный лог (trace), содержащий исходный промпт, ответ модели, время выполнения и стоимость запроса, что значительно упрощает анализ и отладку приложения.
