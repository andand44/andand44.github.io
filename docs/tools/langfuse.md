# Langfuse

## Определение

Langfuse — это платформа с открытым исходным кодом для инженерии LLM (LLM engineering platform). Она предоставляет инструменты для трассировки (tracing), мониторинга, оценки (evaluation) и отладки приложений, построенных на базе больших языковых моделей (LLM). Langfuse помогает разработчикам отслеживать каждый шаг работы их LLM-агентов и цепочек, собирая данные о запросах, ответах, затратах и задержках.

## Зачем нужно

Разработка приложений на базе LLM часто сталкивается с проблемой "черного ящика": сложно понять, почему модель выдала тот или иной результат, сколько это стоило и где произошла ошибка. Langfuse решает эти проблемы, предоставляя:

1. **Трассировка (Tracing):** Полная видимость вложенных вызовов LLM, использования инструментов, запросов к базам данных (RAG) и другой логики приложения.
2. **Мониторинг и аналитика:** Отслеживание затрат (токенов), задержек (latency) и качества ответов в реальном времени.
3. **Оценка (Evaluation):** Инструменты для сбора обратной связи от пользователей, проведения A/B тестирования промптов и автоматической оценки качества.
4. **Управление промптами (Prompt Management):** Централизованное хранение, версионирование и деплой промптов без необходимости пересобирать код приложения.

## Пример

Допустим, вы разрабатываете чат-бота с использованием OpenAI и хотите отслеживать его работу. Вот как можно интегрировать Langfuse с помощью декоратора `@observe()` в Python:

```python
from langfuse.decorators import observe
from openai import OpenAI

client = OpenAI()

@observe()
def get_answer(user_question: str):
    # Этот вызов будет автоматически отслежен Langfuse
    response = client.chat.completions.create(
        model="gpt-3.5-turbo",
        messages=[{"role": "user", "content": user_question}]
    )
    
    return response.choices[0].message.content

# Вызов функции
get_answer("Как мне сбросить пароль?")
```

В результате в дашборде Langfuse вы увидите подробное дерево вызовов (trace), где будет указан промпт, ответ модели, количество потраченных токенов, стоимость запроса и время выполнения. Это позволяет быстро находить узкие места и оптимизировать работу приложения.
