# Pandas

## Определение

Pandas — это мощная библиотека с открытым исходным кодом для языка программирования Python, предназначенная для обработки и анализа структурированных данных. Она предоставляет высокоуровневые структуры данных, такие как `DataFrame` (двумерная таблица) и `Series` (одномерный массив), которые делают работу с табличными данными и временными рядами интуитивно понятной и эффективной.

## Зачем нужно

Pandas является стандартом де-факто в экосистеме Data Science и аналитики на Python. Она используется для решения следующих задач:
- **Загрузка и сохранение данных:** поддержка чтения и записи в различные форматы (CSV, Excel, SQL, JSON, Parquet и др.).
- **Очистка данных (Data Cleaning):** удобные инструменты для обработки пропущенных значений, удаления дубликатов и фильтрации аномалий.
- **Трансформация и агрегация:** мощные методы для группировки данных (groupby), создания сводных таблиц, слияния и изменения формы наборов данных.
- **Анализ данных:** быстрый расчет статистических показателей, работа с временными рядами и подготовка данных для машинного обучения.

## Пример

Ниже приведен базовый пример создания `DataFrame`, фильтрации данных и их группировки с использованием Pandas:

```python
import pandas as pd

# Создание словаря с исходными данными
data = {
    'Сотрудник': ['Иван', 'Мария', 'Петр', 'Анна'],
    'Отдел': ['IT', 'HR', 'IT', 'Маркетинг'],
    'Зарплата': [100000, 80000, 120000, 90000]
}

# Создание DataFrame
df = pd.DataFrame(data)

print("Исходные данные:")
print(df)

# Фильтрация: выбор сотрудников из IT-отдела
it_employees = df[df['Отдел'] == 'IT']
print("\nСотрудники IT отдела:")
print(it_employees)

# Агрегация: расчет средней зарплаты по отделам
average_salary = df.groupby('Отдел')['Зарплата'].mean()
print("\nСредняя зарплата по отделам:")
print(average_salary)
```
