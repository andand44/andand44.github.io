# BeautifulSoup4

## Определение

**BeautifulSoup4** (BS4) — это библиотека для языка Python, предназначенная для парсинга (разбора) документов в форматах HTML и XML. Она преобразует сложную разметку в структурированное дерево объектов Python, предоставляя интуитивно понятные методы для навигации, поиска и извлечения данных.

## Зачем нужно

BeautifulSoup4 является одним из самых популярных инструментов для веб-скрапинга (автоматизированного сбора данных с веб-сайтов). Она используется для решения следующих задач:

- **Извлечение контента:** Получение текстов, ссылок, изображений и таблиц из веб-страниц.
- **Поиск и навигация:** Быстрый поиск элементов по тегам, CSS-классам, идентификаторам (id) и другим атрибутам.
- **Работа с невалидным кодом:** Способность корректно обрабатывать «битый» или некорректный HTML-код, восстанавливая его структуру.
- **Автоматизация:** Применяется в парсинге новостей, мониторинге цен конкурентов, сборе статистики и анализе данных.

## Пример

Ниже приведен пример использования BeautifulSoup4 совместно с библиотекой `requests` для получения заголовка веб-страницы и извлечения всех ссылок с нее:

```python
import requests
from bs4 import BeautifulSoup

# 1. Загружаем HTML-код страницы
url = 'https://example.com'
response = requests.get(url)

# 2. Создаем объект BeautifulSoup (используя встроенный парсер)
soup = BeautifulSoup(response.text, 'html.parser')

# 3. Извлекаем заголовок страницы (тег <title>)
page_title = soup.title.string
print(f'Заголовок страницы: {page_title}')

# 4. Находим все теги <a> и извлекаем атрибут href
print('Ссылки на странице:')
for link in soup.find_all('a'):
    print(link.get('href'))
```
