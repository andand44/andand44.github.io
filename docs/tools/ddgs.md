# ddgs

### Определение

**DDGS** (DuckDuckGo Search) — это программный инструмент (чаще всего одноименная Python-библиотека `duckduckgo_search`), предоставляющий интерфейс для выполнения поисковых запросов в поисковой системе DuckDuckGo. Инструмент позволяет разработчикам автоматизировать получение результатов поиска (текста, изображений, новостей, видео) без необходимости использования официальных платных API. В контексте разработки ИИ-систем DDGS часто выступает в роли «инструмента» (tool) для LLM-агентов, обеспечивая им доступ к сети Интернет.

### Зачем нужно

1. **Доступ к актуальным данным для LLM**: Большие языковые модели имеют ограниченную базу знаний (дату отсечения). DDGS позволяет подключать их к интернету для поиска информации в реальном времени (реализация паттерна RAG — Retrieval-Augmented Generation).
2. **Отсутствие необходимости в API-ключах**: В отличие от поисковых API Google или Bing, библиотека DDGS не требует сложной регистрации, получения ключей и привязки платежных данных (хотя имеет лимиты на частоту запросов).
3. **Автоматизация и парсинг**: Удобна для быстрого сбора данных, мониторинга упоминаний брендов, агрегации новостей и создания датасетов для машинного обучения.
4. **Конфиденциальность**: Использует поисковую систему DuckDuckGo, которая известна своим подходом к неотслеживанию действий пользователей.

### Пример

Пример использования библиотеки `duckduckgo_search` (которая предоставляет класс `DDGS`) на языке Python для получения текстовых результатов поиска:

```python
from duckduckgo_search import DDGS

# Инициализация сессии поиска
with DDGS() as ddgs:
    # Выполнение поискового запроса с ограничением в 3 результата
    results = ddgs.text("последние новости искусственного интеллекта", max_results=3)
    
    # Обработка и вывод результатов
    for i, result in enumerate(results, 1):
        print(f"Результат {i}:")
        print(f"Заголовок: {result['title']}")
        print(f"Ссылка: {result['href']}")
        print(f"Краткое описание: {result['body']}\n")
```
