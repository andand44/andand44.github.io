# ddgs

## Определение
DDGS (DuckDuckGo Search) — это программный инструмент (чаще всего библиотека для языка Python), предоставляющий удобный интерфейс для выполнения поисковых запросов в поисковой системе DuckDuckGo. Он позволяет разработчикам извлекать результаты поиска (веб-страницы, изображения, новости) в структурированном виде напрямую из кода, минуя необходимость ручного парсинга HTML-страниц.

## Зачем нужно
Инструмент DDGS необходим для автоматизации сбора данных из интернета. Основные сценарии его использования включают:
- **Разработка ИИ-агентов и RAG-систем:** предоставление большим языковым моделям (LLM) доступа к актуальной информации из сети в реальном времени.
- **Автоматизированный парсинг:** быстрый сбор заголовков, URL-адресов и кратких описаний (сниппетов) по заданным ключевым словам.
- **Бесплатная альтернатива API:** DuckDuckGo позволяет выполнять запросы без обязательной регистрации и получения платных API-ключей, что делает DDGS отличным решением для прототипирования и пет-проектов.

## Пример
Пример использования библиотеки `duckduckgo_search` (которая предоставляет класс `DDGS`) на языке Python:

```python
from duckduckgo_search import DDGS

# Инициализация клиента
with DDGS() as ddgs:
    # Выполнение текстового поискового запроса
    results = ddgs.text("машинное обучение", max_results=3)
    
    # Вывод результатов
    for result in results:
        print(f"Заголовок: {result['title']}")
        print(f"Ссылка: {result['href']}")
        print(f"Описание: {result['body']}\n")
```
