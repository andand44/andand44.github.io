# pip

## Определение
**pip** (рекурсивный акроним от *Pip Installs Packages*) — это стандартный менеджер пакетов для языка программирования Python. Он представляет собой инструмент командной строки, который позволяет устанавливать, обновлять и удалять программные пакеты и библиотеки. По умолчанию pip загружает пакеты из официального репозитория Python Package Index (PyPI).

## Зачем нужно
pip решает проблему ручного управления зависимостями в проектах на Python. Он автоматизирует процесс поиска, скачивания и установки библиотек, а также отслеживает их совместимость. С помощью pip разработчики могут:
- Быстро устанавливать сторонние библиотеки одной командой.
- Управлять версиями пакетов (обновлять или откатывать до нужной версии).
- Формировать списки зависимостей (например, в файле `requirements.txt`) для легкого и быстрого развертывания проекта на других компьютерах или серверах.

## Пример
Самый частый сценарий использования pip — установка библиотеки. Например, чтобы установить популярную библиотеку для работы с HTTP-запросами `requests`, достаточно выполнить в терминале следующую команду:

```bash
pip install requests
```

Чтобы сохранить все зависимости текущего проекта в файл, используется команда:

```bash
pip freeze > requirements.txt
```

А для установки всех пакетов из этого файла (например, при клонировании чужого проекта):

```bash
pip install -r requirements.txt
```
