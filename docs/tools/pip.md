# pip

## Определение
**pip** (рекурсивный акроним от *Pip Installs Packages*) — это стандартный менеджер пакетов для языка программирования Python. Он представляет собой инструмент командной строки, который позволяет находить, загружать, устанавливать, обновлять и удалять библиотеки и фреймворки из централизованного репозитория Python Package Index (PyPI) и других источников.

## Зачем нужно
- **Управление зависимостями:** pip автоматически разрешает и устанавливает зависимости, необходимые для работы целевой библиотеки, избавляя разработчиков от ручного поиска и скачивания.
- **Изоляция окружений:** В сочетании с инструментами виртуализации (например, `venv`), pip позволяет устанавливать пакеты локально для конкретного проекта, предотвращая конфликты версий между разными приложениями на одном компьютере.
- **Воспроизводимость проектов:** С помощью pip можно зафиксировать все используемые библиотеки в файле `requirements.txt`, что позволяет другим разработчикам (или серверам) быстро развернуть идентичное окружение.
- **Экосистема:** Является стандартом де-факто в сообществе Python и поставляется в комплекте с официальными дистрибутивами Python (начиная с версии 3.4).

## Пример
Работа с pip осуществляется через командную строку (терминал). Вот основные команды:

**Установка пакета** (например, популярной библиотеки для HTTP-запросов `requests`):
```bash
pip install requests
```

**Установка конкретной версии пакета:**
```bash
pip install requests==2.28.1
```

**Обновление пакета до последней версии:**
```bash
pip install --upgrade requests
```

**Удаление пакета:**
```bash
pip uninstall requests
```

**Сохранение списка всех установленных зависимостей в файл:**
```bash
pip freeze > requirements.txt
```

**Установка всех зависимостей из файла (часто используется при развертывании проектов):**
```bash
pip install -r requirements.txt
```
