# venv

### Определение

`venv` (Virtual Environment) — это стандартный встроенный модуль в Python (начиная с версии 3.3), предназначенный для создания изолированных виртуальных окружений. Виртуальное окружение представляет собой отдельную директорию, содержащую собственную копию (или символическую ссылку) интерпретатора Python и изолированное пространство для установки библиотек.

### Зачем нужно

`venv` необходим для решения следующих задач:

1. **Изоляция зависимостей.** Разные проекты могут требовать разные версии одних и тех же библиотек. Виртуальные окружения позволяют устанавливать нужные версии пакетов для каждого проекта отдельно, предотвращая конфликты.
2. **Чистота системы.** Помогает не загромождать глобальное пространство имен Python пакетами, которые нужны только для одного конкретного проекта.
3. **Воспроизводимость.** Упрощает формирование списка зависимостей (например, через `pip freeze > requirements.txt`), что позволяет другим разработчикам или CI/CD системам легко развернуть идентичную среду.

### Пример

Работа с `venv` обычно происходит через терминал.

**1. Создание окружения**
В корневой папке проекта выполните команду (где `myenv` — имя папки окружения):
```bash
python -m venv myenv
```

**2. Активация окружения**
Для Windows:
```bash
myenv\Scripts\activate
```
Для macOS и Linux:
```bash
source myenv/bin/activate
```
После активации в терминале появится префикс `(myenv)`.

**3. Установка пакетов**
Установленные пакеты попадут только в активное виртуальное окружение:
```bash
pip install flask
```

**4. Деактивация**
Для выхода из виртуального окружения используйте команду:
```bash
deactivate
```
