# venv

## Определение

`venv` (Virtual Environment) — это встроенный модуль в Python (начиная с версии 3.3), предназначенный для создания изолированных виртуальных окружений. Виртуальное окружение представляет собой отдельную директорию, которая содержит собственную копию интерпретатора Python и изолированное пространство для установки сторонних библиотек и пакетов.

## Зачем нужно

1. **Изоляция зависимостей:** Разные проекты могут требовать разные версии одних и тех же библиотек. `venv` позволяет устанавливать необходимые версии пакетов для каждого проекта отдельно, предотвращая конфликты.
2. **Чистота системы:** Помогает избежать загромождения глобального пространства имен Python пакетами, которые требуются только для одного конкретного проекта.
3. **Воспроизводимость:** Упрощает управление зависимостями и создание файла `requirements.txt`, что позволяет другим разработчикам или серверам быстро и точно воссоздать окружение проекта.

## Пример

Ниже приведен пример создания виртуального окружения, его активации и установки зависимостей:

```bash
# Создание виртуального окружения в папке 'myenv'
python -m venv myenv

# Активация окружения (для Linux и macOS)
source myenv/bin/activate

# Активация окружения (для Windows)
# myenv\Scripts\activate

# Установка пакета внутри активного виртуального окружения
pip install requests

# Сохранение зависимостей в файл
pip freeze > requirements.txt

# Выход из виртуального окружения
deactivate
```
