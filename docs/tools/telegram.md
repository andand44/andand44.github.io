# Telegram

## Определение

Telegram — это облачный кроссплатформенный мессенджер и коммуникационная платформа, созданная Павлом Дуровым в 2013 году. Сервис использует проприетарный протокол MTProto и предоставляет клиенты для мобильных и десктопных ОС, а также веб-версию. Помимо личных и групповых чатов, Telegram поддерживает каналы, секретные чаты с сквозным шифрованием, голосовые и видеозвонки, обмен файлами и развитую экосистему ботов через Bot API.

## Зачем нужно

- **Безопасность и приватность**: секретные чаты с end-to-end шифрованием, облачные чаты с синхронизацией между устройствами.
- **Масштабируемые сообщества**: группы до сотен тысяч участников и каналы с неограниченной аудиторией для вещания контента.
- **Автоматизация**: Telegram Bot API и библиотеки позволяют создавать ботов для уведомлений, интеграций, платежей и мини-приложений.
- **Обмен данными**: передача файлов большого объёма, медиа и документов без жёстких ограничений по размеру.
- **Кроссплатформенность**: единый аккаунт работает на смартфонах, ПК и в браузере.

## Пример

Пример отправки сообщения через Telegram Bot API на Python:

```python
import requests

TOKEN = "YOUR_BOT_TOKEN"
CHAT_ID = "YOUR_CHAT_ID"
text = "Привет из статьи!"

url = f"https://api.telegram.org/bot{TOKEN}/sendMessage"
payload = {"chat_id": CHAT_ID, "text": text}

response = requests.post(url, json=payload)
print(response.json())
```

Этот скрипт отправляет текстовое сообщение в указанный чат от имени вашего бота. Для работы нужно создать бота через [@BotFather](https://t.me/BotFather) и получить токен.
