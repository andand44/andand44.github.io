# Cloudflare Worker

## Определение

Cloudflare Workers — это бессерверная (serverless) вычислительная платформа от компании Cloudflare, которая позволяет разработчикам запускать код (на JavaScript, TypeScript, Rust или WebAssembly) на границе сети (edge network) Cloudflare, распределенной по всему миру. В отличие от традиционных облачных функций, Workers используют изоляты V8 (V8 isolates) вместо контейнеров или виртуальных машин, что обеспечивает практически нулевое время холодного старта и высокую эффективность использования ресурсов.

## Зачем нужно

Cloudflare Workers необходимы для создания высокопроизводительных, глобально распределенных приложений с минимальной задержкой (low latency). Поскольку код выполняется максимально близко к конечному пользователю, это помогает решать следующие задачи:
- **Снижение нагрузки на основной сервер (origin):** Кэширование, модификация запросов и ответов на уровне CDN.
- **Персонализация и A/B тестирование:** Изменение контента на лету без задержек для пользователя.
- **Безопасность:** Реализация аутентификации (например, проверка JWT-токенов), защита от ботов и фильтрация вредоносного трафика до того, как он достигнет бэкенда.
- **Создание API и микросервисов:** Быстрое развертывание легковесных сервисов без необходимости управления серверной инфраструктурой.

## Пример

Ниже приведен простой пример Worker'а на JavaScript, который перехватывает входящий запрос, определяет страну пользователя (с помощью встроенных данных Cloudflare) и возвращает персонализированный текстовый ответ с кастомным заголовком:

```javascript
addEventListener('fetch', event => {
  event.respondWith(handleRequest(event.request))
})

async function handleRequest(request) {
  // Получаем код страны из объекта request.cf
  const country = request.cf?.country || 'Unknown';
  
  // Формируем ответ
  const response = new Response(`Привет! Ваш запрос обработан на границе сети. Вы находитесь в стране: ${country}`, {
    status: 200,
    headers: {
      'Content-Type': 'text/plain; charset=UTF-8',
      'X-Worker-Processed': 'true'
    }
  });

  return response;
}
```
