# GitHub Actions

## Определение
GitHub Actions — это платформа непрерывной интеграции и непрерывной доставки (CI/CD), встроенная непосредственно в GitHub. Она позволяет автоматизировать сборку, тестирование и развертывание приложений прямо из репозитория. Рабочие процессы (workflows) настраиваются с помощью YAML-файлов и запускаются в ответ на определенные события (например, push, создание pull request или по расписанию).

## Зачем нужно
GitHub Actions помогает разработчикам автоматизировать рутинные задачи и ускорять цикл разработки ПО. Основные цели использования:
- **CI/CD:** Автоматический запуск тестов и сборок при каждом изменении кода, а также автоматическое развертывание на продакшен или стейджинг.
- **Автоматизация репозитория:** Управление issue, pull request'ами, автоматическое назначение ревьюеров и закрытие неактивных задач.
- **Кроссплатформенность:** Возможность тестировать код на разных операционных системах (Linux, macOS, Windows) и версиях языков программирования.

## Пример
Простейший workflow для Node.js проекта, который устанавливает зависимости и запускает тесты при каждом push в ветку `main`. Файл конфигурации располагается по пути `.github/workflows/test.yml`:

```yaml
name: Node.js CI

on:
  push:
    branches: [ "main" ]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v3
    - name: Use Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18.x'
    - run: npm install
    - run: npm test
```
