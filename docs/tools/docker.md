# Docker

## Определение
Docker — это платформа с открытым исходным кодом, предназначенная для автоматизации развертывания, масштабирования и управления приложениями в изолированных средах, называемых контейнерами. Контейнер позволяет упаковать приложение вместе со всеми его зависимостями, библиотеками и конфигурационными файлами в единый стандартизированный блок, который гарантированно будет работать одинаково на любой инфраструктуре.

## Зачем нужно
Docker решает извечную проблему «но у меня на компьютере всё работает», обеспечивая полную идентичность окружения на всех этапах жизненного цикла программы: от разработки до эксплуатации (продакшена).

Основные преимущества:
- **Изоляция:** Приложения и их зависимости изолированы друг от друга, что исключает конфликты версий библиотек на одном сервере.
- **Портативность:** Контейнеры можно легко переносить между локальными машинами, серверами и облачными провайдерами.
- **Эффективность:** В отличие от традиционных виртуальных машин, контейнеры совместно используют ядро хостовой операционной системы, что делает их очень легковесными и быстрыми на запуск.
- **Упрощение CI/CD и микросервисов:** Docker является стандартом де-факто для построения микросервисной архитектуры и легко интегрируется в пайплайны непрерывной интеграции и поставки.

## Пример
Рассмотрим базовый пример упаковки (контейнеризации) простого веб-приложения на Python.

1. Создайте текстовый файл с именем `Dockerfile` в корне вашего проекта:
```dockerfile
# Используем официальный базовый образ с Python
FROM python:3.9-slim

# Устанавливаем рабочую директорию внутри контейнера
WORKDIR /app

# Копируем файл с зависимостями и устанавливаем их
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Копируем исходный код проекта в контейнер
COPY . .

# Открываем порт 5000 для внешнего доступа
EXPOSE 5000

# Указываем команду для запуска приложения
CMD ["python", "app.py"]
```

2. Соберите Docker-образ с помощью команды в терминале:
```bash
docker build -t my-python-app .
```

3. Запустите контейнер на основе созданного образа:
```bash
docker run -d -p 5000:5000 my-python-app
```

В результате приложение будет запущено в изолированном контейнере и станет доступно по адресу `http://localhost:5000`, даже если на вашем локальном компьютере не установлен Python.
