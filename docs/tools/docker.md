# Docker

## Определение
Docker — это платформа с открытым исходным кодом, предназначенная для автоматизации развертывания, масштабирования и управления приложениями с использованием контейнеризации. Контейнеры позволяют упаковать приложение со всеми его зависимостями, библиотеками и конфигурационными файлами в единый стандартизированный блок, который может работать в любой среде (на локальной машине, на сервере или в облаке).

## Зачем нужно
Docker решает проблему "работает на моей машине" (it works on my machine). Основные цели и преимущества использования Docker:
1. **Изоляция:** Приложения и их зависимости изолированы друг от друга и от основной системы.
2. **Портативность:** Контейнеры можно легко переносить между различными средами (разработка, тестирование, продакшен) без изменений в коде.
3. **Эффективность:** Контейнеры используют ресурсы ядра операционной системы хоста, что делает их более легковесными и быстрыми по сравнению с традиционными виртуальными машинами.
4. **Масштабируемость:** Упрощает горизонтальное масштабирование приложений и интеграцию с системами оркестрации, такими как Kubernetes.

## Пример
Рассмотрим простой пример создания Docker-контейнера для веб-приложения на Python (Flask).

1. Создайте файл `app.py`:
```python
from flask import Flask
app = Flask(__name__)

@app.route('/')
def hello():
    return "Hello from Docker!"

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

2. Создайте файл `Dockerfile` (инструкция по сборке образа):
```dockerfile
# Используем базовый образ Python
FROM python:3.9-slim

# Устанавливаем рабочую директорию
WORKDIR /app

# Копируем файлы в контейнер
COPY . /app

# Устанавливаем зависимости
RUN pip install flask

# Открываем порт 5000
EXPOSE 5000

# Команда для запуска приложения
CMD ["python", "app.py"]
```

3. Сборка и запуск контейнера в терминале:
```bash
# Сборка образа
docker build -t my-flask-app .

# Запуск контейнера
docker run -p 5000:5000 my-flask-app
```
После выполнения этих команд приложение будет доступно по адресу `http://localhost:5000`.
