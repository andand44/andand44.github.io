# Ollama

## Определение
**Ollama** — это инструмент с открытым исходным кодом, предназначенный для упрощения запуска и управления большими языковыми моделями (LLM) на локальном оборудовании. Он инкапсулирует веса моделей, параметры и зависимости в единый формат, что позволяет разработчикам без глубоких знаний инфраструктуры машинного обучения разворачивать популярные модели (например, Llama 3, Mistral, Gemma) на своих компьютерах.

## Зачем нужно
Основная цель Ollama — устранить сложности, связанные с локальным развертыванием LLM. Инструмент берет на себя управление зависимостями, оптимизацию использования видеопамяти (GPU) и центрального процессора (CPU).

Ключевые преимущества:
- **Приватность данных:** все запросы и данные обрабатываются локально, без передачи в облако.
- **Простота:** установка и запуск модели осуществляются одной командой в терминале.
- **Кроссплатформенность:** работает на macOS, Linux и Windows.
- **Наличие API:** предоставляет локальный REST API, что позволяет легко интегрировать языковые модели в сторонние приложения и скрипты.

## Пример
Работа с Ollama обычно происходит через командную строку или API.

1. **Запуск модели:**
   Чтобы скачать (при первом запуске) и запустить модель Llama 3, достаточно выполнить команду:
   ```bash
   ollama run llama3
   ```

2. **Общение с моделью:**
   После загрузки откроется интерактивный чат прямо в терминале:
   ```text
   >>> Напиши функцию на Python для вычисления факториала
   def factorial(n):
       if n == 0:
           return 1
       else:
           return n * factorial(n-1)
   ```

3. **Использование REST API:**
   Ollama автоматически поднимает локальный сервер (по умолчанию на порту 11434). Отправить запрос можно с помощью `curl`:
   ```bash
   curl http://localhost:11434/api/generate -d '{
     "model": "llama3",
     "prompt": "Почему трава зеленая?",
     "stream": false
   }'
   ```
