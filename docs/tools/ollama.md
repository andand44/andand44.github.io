# Ollama

### Определение

**Ollama** — это инструмент с открытым исходным кодом, который позволяет легко запускать большие языковые модели (LLM), такие как Llama 3, Mistral, Gemma и другие, на локальном компьютере. Он упаковывает веса моделей, конфигурации и зависимости в единый формат, предоставляя простой интерфейс командной строки и REST API для взаимодействия с моделями без необходимости сложной ручной настройки окружения (например, установки драйверов или Python-библиотек).

### Зачем нужно

Ollama решает проблему высокой сложности развертывания и запуска LLM на локальном оборудовании. Основные цели и преимущества использования Ollama:
- **Конфиденциальность и безопасность:** Все данные обрабатываются локально и не передаются в облачные сервисы третьих лиц.
- **Простота использования:** Установка и запуск модели занимают считанные минуты (например, достаточно одной команды `ollama run llama3`).
- **Экономия средств:** Отсутствие необходимости оплачивать облачные API на этапе разработки, прототипирования и тестирования.
- **Офлайн-доступ:** Возможность работать с языковыми моделями без активного подключения к интернету.
- **Кроссплатформенность:** Нативная поддержка macOS, Linux и Windows.

### Пример

Пример использования Ollama для запуска модели и взаимодействия с ней.

**1. Запуск модели через терминал:**
Сначала необходимо установить Ollama, а затем выполнить команду для загрузки и запуска модели (например, Llama 3):
```bash
ollama run llama3
```
После загрузки можно напрямую общаться с моделью в интерактивном режиме терминала.

**2. Использование REST API (через curl):**
Ollama автоматически запускает локальный сервер (по умолчанию на порту `11434`). Можно отправить программный запрос к модели:
```bash
curl http://localhost:11434/api/generate -d '{
  "model": "llama3",
  "prompt": "Почему небо синее?",
  "stream": false
}'
```

**3. Интеграция в Python:**
```python
import requests
import json

url = "http://localhost:11434/api/generate"
data = {
    "model": "llama3",
    "prompt": "Напиши короткое стихотворение про программирование.",
    "stream": False
}

response = requests.post(url, json=data)
print(json.loads(response.text)["response"])
```
