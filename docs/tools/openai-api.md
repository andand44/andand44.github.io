# OpenAI API

## Определение

OpenAI API — это облачный HTTP-интерфейс (API) от компании OpenAI, который даёт разработчикам доступ к большим языковым моделям (LLM), таким как GPT-4o, GPT-4, GPT-3.5, а также к другим моделям: генерации изображений (DALL·E), распознавания речи (Whisper) и получения эмбеддингов. Через API можно отправлять текстовые запросы (prompts) и получать сгенерированные ответы, код, классификации, векторные представления и другие результаты.

## Зачем нужно

- **Быстрая интеграция ИИ**: не нужно самостоятельно обучать и разворачивать модели.
- **Разнообразие задач**: чат-боты, виртуальные ассистенты, генерация контента, анализ тональности, поиск по базе знаний (RAG), помощь в программировании.
- **Масштабируемость и актуальность**: OpenAI управляет инфраструктурой, обновляет модели и заботится о безопасности.
- **Гибкая модель оплаты**: pay-as-you-go, выбор модели и параметров под конкретную задачу и бюджет.

## Пример

Пример вызова Chat Completions API на Python с использованием официального SDK:

```python
from openai import OpenAI

client = OpenAI(api_key='sk-...')

response = client.chat.completions.create(
    model='gpt-4o-mini',
    messages=[
        {'role': 'system', 'content': 'Ты полезный ассистент.'},
        {'role': 'user', 'content': 'Привет! Расскажи, что такое OpenAI API.'}
    ]
)

print(response.choices[0].message.content)
```
