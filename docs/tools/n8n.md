# n8n

## Определение

n8n — это платформа для автоматизации рабочих процессов с открытым исходным кодом (модель fair-code) и визуальным редактором на основе узлов (nodes). Она позволяет соединять различные сервисы, базы данных и API в единый сценарий без необходимости писать связующий код целиком. Каждый узел выполняет действие: получает данные, преобразует их, отправляет запрос или запускает логику. n8n можно развернуть на собственном сервере (self-hosted) или использовать в облаке.

## Зачем нужно

- **Экономия времени**: автоматизация рутинных операций (синхронизация данных, уведомления, отчёты).
- **Гибкость**: поддержка HTTP-запросов, Webhooks, JavaScript/Python в Function-узлах и более 400 готовых интеграций.
- **Контроль данных**: возможность self-hosting повышает приватность и безопасность по сравнению с полностью закрытыми SaaS-аналогами.
- **Масштабируемость**: от простых «если — то» цепочек до сложных ETL-процессов и оркестрации ИИ-агентов.
- **Снижение порога входа**: визуальный интерфейс подходит не только разработчикам, но и аналитикам или менеджерам.

## Пример

Допустим, нужно при появлении новой строки в Google Sheets отправлять сообщение в Telegram и сохранять событие в базу данных.

**Шаги в n8n:**

1. Узел **Google Sheets Trigger** — отслеживает новые строки.
2. Узел **Set** — приводит данные к нужному формату (например, извлекает `name` и `email`).
3. Узел **Telegram** — отправляет сообщение `Новая заявка: {{ $json.name }}`.
4. Узел **Postgres** — выполняет `INSERT INTO leads (name, email) VALUES (...)`.

Пример кода в **Function**-узле для подготовки текста:

```javascript
return items.map(item => {
  const name = item.json.name ?? 'Без имени';
  return {
    json: {
      ...item.json,
      message: `Поступила новая заявка от ${name}`
    }
  };
});
```

Такой workflow запускается автоматически по триггеру и избавляет от ручного копирования данных между сервисами.
