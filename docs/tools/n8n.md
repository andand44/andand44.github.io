# n8n

## Определение

n8n (произносится как "n-eight-n") — это инструмент автоматизации рабочих процессов (workflow automation) с открытым исходным кодом. Он позволяет связывать различные приложения, сервисы и API для автоматизации рутинных задач без необходимости написания сложного кода (хотя возможность использования JavaScript или Python также поддерживается). Платформа использует визуальный редактор на основе узлов (nodes), где каждый узел представляет собой определенное действие, триггер или интеграцию с приложением.

## Зачем нужно

n8n необходим для автоматизации бизнес-процессов и повседневных задач. Он помогает:
- **Экономить время:** Автоматизирует рутинные операции (например, перенос данных между CRM и таблицами).
- **Интегрировать системы:** Объединяет разрозненные сервисы (Slack, Google Sheets, Telegram, базы данных и др.) в единую экосистему.
- **Создавать сложные сценарии:** Позволяет строить многоступенчатые логические цепочки с условиями, циклами и обработкой ошибок.
- **Обеспечивать контроль над данными:** В отличие от многих облачных аналогов (например, Zapier), n8n можно развернуть на собственном сервере (self-hosted), что гарантирует высокий уровень безопасности и конфиденциальности данных.

## Пример

Представим задачу: при получении нового письма на Gmail с темой "Счет", необходимо сохранить вложение в Google Drive и отправить уведомление в Telegram-чат.

В n8n этот процесс будет выглядеть как цепочка из трех узлов:
1. **Gmail Trigger (Триггер):** Активирует сценарий, когда приходит новое письмо с указанной темой.
2. **Google Drive (Действие):** Берет вложение из полученного письма и загружает его в указанную папку на Google Drive.
3. **Telegram (Действие):** Отправляет сообщение в нужный чат с текстом: "Получен новый счет и сохранен на диске!".

Визуально эти узлы соединяются стрелками в редакторе n8n, и после активации workflow (рабочего процесса) он будет работать автоматически в фоновом режиме.
