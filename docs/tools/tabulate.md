# Tabulate

## Определение

**Tabulate** — это библиотека для языка программирования Python, которая предназначена для простого и красивого форматирования табличных данных. Она принимает на вход данные в различных форматах (списки списков, словари, объекты `pandas.DataFrame`) и преобразует их в аккуратные текстовые таблицы. Библиотека поддерживает множество стилей оформления, таких как `plain`, `simple`, `grid`, `pipe` (для Markdown) и другие.

## Зачем нужно

Tabulate используется для повышения читаемости данных при выводе в консоль, логи или текстовые файлы. 

**Основные сценарии использования:**
1. **Автоматическое выравнивание:** Избавляет разработчика от необходимости вручную рассчитывать пробелы для выравнивания столбцов.
2. **Создание CLI-инструментов:** Помогает формировать понятные и структурированные таблицы прямо в терминале.
3. **Генерация документации:** Позволяет легко конвертировать данные в таблицы формата Markdown, HTML или LaTeX для вставки в отчеты и документацию.
4. **Быстрая отладка:** Упрощает визуальный анализ структур данных в процессе разработки.

## Пример

Сначала установите библиотеку через терминал:

```bash
pip install tabulate
```

Пример кода на Python:

```python
from tabulate import tabulate

# Данные для таблицы
data = [
    ["Алиса", 24, "Москва"],
    ["Боб", 27, "Санкт-Петербург"],
    ["Чарли", 22, "Казань"]
]

# Заголовки столбцов
headers = ["Имя", "Возраст", "Город"]

# Генерация и вывод таблицы в стиле 'grid'
print(tabulate(data, headers=headers, tablefmt="grid"))
```

**Результат в консоли:**

```text
+--------+-----------+-----------------+
| Имя    |   Возраст | Город           |
+========+===========+=================+
| Алиса  |        24 | Москва          |
+--------+-----------+-----------------+
| Боб    |        27 | Санкт-Петербург |
+--------+-----------+-----------------+
| Чарли  |        22 | Казань          |
+--------+-----------+-----------------+
```
