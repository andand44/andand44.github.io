# GLiNER2.5

## Определение

GLiNER (Generalist and Lightweight Model for Named Entity Recognition) — это нейросетевая модель для извлечения именованных сущностей из текста. Версия GLiNER2.5 представляет собой улучшенную версию, которая поддерживает zero-shot recognition, то есть способность находить сущности произвольных типов без дополнительного обучения. Модель использует архитектуру на основе трансформеров, аналогичную языковым моделям, но оптимизирована для эффективной работы с NER.

## Зачем нужно

Традиционные NER-системы требуют обучения на размеченных данных для каждого типа сущностей. LLM (большие языковые модели) могут справляться с NER, но они тяжёлые и медленные, а также не всегда точны в деталях. GLiNER2.5 сочетает преимущества обоих подходов: она лёгкая, быстрая, может работать на CPU и распознаёт любые типы сущностей "на лету" по описанию. Это необходимо для задач, где нужно быстро и гибко извлекать информацию из неструктурированных текстов, например, при анализе документов, построении графов знаний или автоматизации обработки заявок.

## Пример

Ниже показано, как использовать GLiNER2.5 с библиотекой `gliner` в Python. Сначала установите пакет: `pip install gliner`.

```python
from gliner import GLiNER

# Загружаем предобученную модель
model = GLiNER.from_pretrained("urchade/gliner_multi_pii-v1")

# Исходный текст
text = "Джон Смит работает в компании Google в Лондоне с 2020 года."

# Список типов сущностей для поиска
labels = ["Persons", "Organizations", "Locations", "Dates"]

# Выполняем NER
entities = model.predict_entities(text, labels)

for entity in entities:
    print(f"{entity['label']}: {entity['text']} (начало: {entity['start']}, конец: {entity['end']})")
```

Результат:

```
Persons: Джон Смит (начало: 0, конец: 10)
Organizations: Google (начало: 20, конец: 26)
Locations: Лондоне (начало: 31, конец: 39)
Dates: 2020 год (начало: 45, конец: 53)
```

Обратите внимание: модель понимает естественные описания типов сущностей и может находить их в тексте даже без специального обучения.
