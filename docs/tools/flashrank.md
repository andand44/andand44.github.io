# Flashrank

## Определение
Flashrank — это сверхлегкая и высокопроизводительная библиотека с открытым исходным кодом на языке Python, предназначенная для реранжирования (reranking) результатов поиска. Она использует оптимизированные модели кросс-энкодеров (cross-encoders), которые позволяют быстро и точно оценивать релевантность документов по отношению к поисковому запросу. Библиотека специально разработана для работы на CPU без необходимости использования тяжеловесных фреймворков, таких как PyTorch или TensorFlow.

## Зачем нужно
В современных системах поиска и RAG-пайплайнах (Retrieval-Augmented Generation) первичный поиск (например, векторный поиск) часто возвращает документы, которые не всегда идеально соответствуют смыслу запроса. Flashrank решает эту проблему, добавляя этап реранжирования.

Основные причины использования Flashrank:
1. **Повышение точности (Precision):** В отличие от векторного поиска, который сравнивает эмбеддинги независимо, кросс-энкодеры анализируют запрос и документ одновременно, находя более глубокие семантические связи.
2. **Скорость и эффективность:** Flashrank работает в десятки раз быстрее стандартных решений на базе Transformers и потребляет минимум памяти, что делает его идеальным для продакшена.
3. **Оптимизация RAG:** Помогает отсеивать нерелевантные данные перед передачей контекста в большую языковую модель (LLM), что экономит токены, ускоряет генерацию и снижает риск галлюцинаций.

## Пример
Ниже приведен простой пример использования Flashrank для реранжирования списка документов по заданному запросу:

```python
from flashrank import Ranker, RerankRequest

# 1. Инициализация ранкера (по умолчанию загружается легкая модель)
ranker = Ranker()

# 2. Подготовка поискового запроса и списка документов
query = "Какая столица Франции?"
passages = [
    {"id": 1, "text": "Берлин является столицей Германии и крупнейшим городом Европейского союза."},
    {"id": 2, "text": "Париж — столица и самый густонаселенный город Франции."},
    {"id": 3, "text": "Франция — трансконтинентальная страна в Западной Европе."},
    {"id": 4, "text": "Рим — столица Италии, расположенная на реке Тибр."}
]

# 3. Создание объекта запроса на реранжирование
rerank_request = RerankRequest(query=query, passages=passages)

# 4. Выполнение реранжирования
results = ranker.rerank(rerank_request)

# 5. Вывод результатов, отсортированных по убыванию релевантности
for result in results:
    print(f"ID: {result['id']} | Score: {result['score']:.4f} | Text: {result['text']}")
```
