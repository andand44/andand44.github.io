# Flashrank

## Определение
Flashrank — это сверхлегкая и высокопроизводительная библиотека с открытым исходным кодом на языке Python, предназначенная для реранжирования (reranking) результатов поиска. Она использует компактные и оптимизированные кросс-энкодерные модели (cross-encoders) для оценки и повторного ранжирования документов по их релевантности к поисковому запросу.

## Зачем нужно
Flashrank применяется для повышения точности поисковых систем и RAG-пайплайнов (Retrieval-Augmented Generation). Первичный поиск (например, векторный или по ключевым словам) часто выдает шумные или не совсем точные результаты. Flashrank решает эту проблему, выполняя роль второго этапа фильтрации:
- **Повышение релевантности:** Точно определяет и поднимает в топ наиболее подходящие документы.
- **Оптимизация RAG:** Позволяет передавать в контекст большой языковой модели (LLM) только самую важную информацию, снижая риск галлюцинаций и улучшая качество генерации.
- **Эффективность:** В отличие от тяжелых моделей реранжирования, Flashrank работает очень быстро даже на CPU, не требует мощных GPU или подключения к платным внешним API.

## Пример
Пример использования Flashrank для реранжирования списка документов на Python:

```python
from flashrank import Ranker, RerankRequest

# Инициализация ранкера (легковесная модель загрузится автоматически)
ranker = Ranker()

# Поисковый запрос
query = "Что такое машинное обучение?"

# Список документов, полученных на этапе первичного поиска
passages = [
    {"id": 1, "text": "Машинное обучение — это раздел искусственного интеллекта."},
    {"id": 2, "text": "Флэшранк используется для реранжирования документов."},
    {"id": 3, "text": "Искусственный интеллект включает в себя машинное обучение и нейросети."}
]

# Создание запроса на реранжирование
rerank_request = RerankRequest(query=query, passages=passages)

# Выполнение реранжирования
results = ranker.rerank(rerank_request)

# Вывод результатов, отсортированных по убыванию релевантности
for result in results:
    print(f"ID: {result['id']} | Score: {result['score']:.4f} | Text: {result['text']}")
```
