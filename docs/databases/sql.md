# SQL

## Определение

SQL (Structured Query Language — язык структурированных запросов) — это стандартизированный декларативный язык программирования, используемый для создания, управления и извлечения данных из реляционных баз данных.

## Зачем нужно

SQL является основным инструментом для работы с реляционными базами данных (такими как PostgreSQL, MySQL, Oracle, SQLite). Он необходим для:
- **Манипуляции данными:** добавление, обновление и удаление записей (CRUD-операции).
- **Извлечения данных:** выполнение сложных выборок с фильтрацией, сортировкой и группировкой.
- **Управления структурой:** создание и изменение таблиц, связей между ними и обеспечение целостности данных.

## Пример

Пример SQL-запроса, который извлекает имена и email пользователей старше 18 лет из таблицы `users`:

```sql
SELECT name, email
FROM users
WHERE age > 18;
```
