# MySQL

## Определение
MySQL — это свободная реляционная система управления базами данных (СУБД). Она использует язык структурированных запросов (SQL) для добавления, доступа и управления содержимым базы данных. MySQL является одним из самых популярных решений для работы с реляционными данными и часто используется в качестве хранилища для веб-приложений (например, в стеке LAMP).

## Зачем нужно
MySQL необходима для надежного и эффективного хранения, структурирования и извлечения данных. 

Основные причины использования MySQL:
- **Высокая производительность:** Оптимизирована для быстрой обработки запросов и работы с большими объемами данных.
- **Масштабируемость:** Поддерживает репликацию (копирование данных на несколько серверов) и кластеризацию, что позволяет масштабировать систему по мере роста нагрузки.
- **Безопасность:** Предоставляет гибкие инструменты для разграничения доступа пользователей и защиты данных.
- **Широкая поддержка:** Имеет огромное сообщество, подробную документацию и совместима с большинством языков программирования и фреймворков.

## Пример
Ниже приведен пример базовых SQL-команд для работы с MySQL: создание таблицы, добавление данных и их выборка.

```sql
-- Создание таблицы пользователей
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Добавление новой записи
INSERT INTO users (username, email) 
VALUES ('john_doe', 'john@example.com');

-- Выборка данных
SELECT id, username, email 
FROM users 
WHERE username = 'john_doe';
```
