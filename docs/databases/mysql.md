# MySQL

## Определение
MySQL — это одна из самых популярных в мире открытых реляционных систем управления базами данных (СУБД). Она использует язык структурированных запросов (SQL) для добавления, изменения, удаления и извлечения данных. Изначально разработанная компанией MySQL AB, на данный момент система принадлежит и поддерживается корпорацией Oracle.

## Зачем нужно
MySQL используется для надежного и быстрого хранения структурированной информации. Основные сценарии применения:
- **Веб-разработка:** Является ключевым компонентом классических стеков технологий, таких как LAMP (Linux, Apache, MySQL, PHP) и LEMP.
- **Целостность и безопасность данных:** Поддерживает транзакции (с использованием движка InnoDB), внешние ключи (FOREIGN KEY) и разграничение прав доступа.
- **Масштабируемость:** Подходит как для небольших сайтов, так и для высоконагруженных корпоративных систем, обеспечивая репликацию, кластеризацию и высокую производительность.

## Пример
Ниже приведен базовый пример SQL-запросов в MySQL: создание таблицы, вставка данных и их выборка.

```sql
-- Создание таблицы пользователей
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL
);

-- Вставка новой записи
INSERT INTO users (username, email) 
VALUES ('john_doe', 'john@example.com');

-- Выборка данных
SELECT id, username, email 
FROM users 
WHERE username = 'john_doe';
```
