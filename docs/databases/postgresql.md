# PostgreSQL

## Определение
PostgreSQL — это мощная объектно-реляционная система управления базами данных (СУБД) с открытым исходным кодом. Она известна своей надежностью, расширяемостью и строгим соответствием стандартам SQL. PostgreSQL поддерживает сложные запросы, внешние ключи, триггеры, обновляемые представления и транзакции с уровнями изоляции (ACID).

## Зачем нужно
PostgreSQL используется для хранения, обработки и извлечения данных в самых разных приложениях — от небольших веб-сайтов до крупных корпоративных систем и аналитических платформ. 
Основные причины использования:
- **Надежность и целостность данных:** Полная поддержка транзакций ACID.
- **Расширяемость:** Возможность добавления пользовательских типов данных, функций и языков программирования.
- **Поддержка сложных структур:** Эффективная работа с JSON, массивами, геопространственными данными (через расширение PostGIS).
- **Масштабируемость:** Способность обрабатывать большие объемы данных и высокую нагрузку.

## Пример
Пример создания таблицы, вставки и выборки данных с использованием SQL в PostgreSQL:

```sql
-- Создание таблицы пользователей
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Вставка данных
INSERT INTO users (username, email) 
VALUES ('john_doe', 'john@example.com');

-- Выборка данных
SELECT * FROM users WHERE username = 'john_doe';
```
