# Redis

## Определение
Redis (REmote DIctionary Server) — это высокопроизводительная нереляционная (NoSQL) база данных типа «ключ-значение», работающая с данными в оперативной памяти (in-memory). Она поддерживает различные структуры данных, такие как строки, списки, хэши, множества и отсортированные множества. Благодаря хранению данных в оперативной памяти, Redis обеспечивает минимальные задержки (менее миллисекунды) и может использоваться как полноценная база данных, кэш или брокер сообщений.

## Зачем нужно
Redis применяется там, где критически важна скорость доступа к данным и высокая пропускная способность. Основные сценарии использования:
- **Кэширование**: самый популярный сценарий. Redis хранит результаты тяжелых запросов к основной БД или вычислений, снижая нагрузку и ускоряя отклик приложения.
- **Управление сессиями**: централизованное хранение сессий пользователей в распределенных системах.
- **Очереди задач и брокер сообщений**: использование механизмов Pub/Sub и списков для асинхронной обработки задач (например, через Celery, Sidekiq или BullMQ).
- **Аналитика в реальном времени и лидерборды**: структуры данных Sorted Sets идеально подходят для создания рейтингов, счетчиков и лент активности.
- **Rate Limiting (ограничение частоты запросов)**: защита API от перегрузки путем подсчета количества запросов с одного IP или токена за определенный период.

## Пример
Пример использования Redis в качестве кэша в Python с использованием библиотеки `redis-py`:

```python
import redis
import json
import time

# Подключение к локальному серверу Redis
cache = redis.Redis(host='localhost', port=6379, db=0)

def get_product_info(product_id):
    cache_key = f"product:{product_id}"
    
    # 1. Пробуем получить данные из кэша
    cached_product = cache.get(cache_key)
    if cached_product:
        print("-> Данные взяты из Redis (быстро)")
        return json.loads(cached_product)
        
    # 2. Если в кэше нет, имитируем долгий запрос к основной БД
    print("-> Данных в кэше нет. Делаем запрос к PostgreSQL...")
    time.sleep(2) # Имитация задержки сети/БД
    product_data = {"id": product_id, "name": "Смартфон", "price": 499}
    
    # 3. Сохраняем результат в Redis на 1 час (3600 секунд)
    cache.setex(cache_key, 3600, json.dumps(product_data))
    return product_data

# Первый запрос (медленный, идет в БД)
get_product_info(101)
# Второй запрос (мгновенный, берется из Redis)
get_product_info(101)
```
