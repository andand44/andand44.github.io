# Redis

## Определение

Redis (Remote Dictionary Server) — это высокопроизводительная система управления базами данных (СУБД) класса NoSQL, работающая в оперативной памяти по принципу «ключ-значение». Помимо простых строк, Redis поддерживает сложные структуры данных, такие как списки, множества, хэши и отсортированные множества, что делает его гибким инструментом для разработчиков.

## Зачем нужно

Redis используется там, где требуется максимальная скорость отклика и высокая пропускная способность. Основные сценарии применения:

* **Кэширование**: самый популярный сценарий. Redis хранит результаты тяжелых запросов к основной базе данных, что значительно ускоряет работу приложения.
* **Управление сессиями**: благодаря высокой скорости и возможности устанавливать время жизни ключей (TTL), Redis идеально подходит для хранения пользовательских сессий.
* **Очереди сообщений и Pub/Sub**: встроенные механизмы позволяют использовать Redis как брокер сообщений для асинхронного взаимодействия между микросервисами.
* **Аналитика в реальном времени и лидерборды**: структуры данных (например, Sorted Sets) позволяют мгновенно обновлять и получать рейтинги, счетчики и статистику.

## Пример

Пример использования Redis в качестве кэша в Python-приложении с использованием библиотеки `redis-py`:

```python
import redis
import json
import time

# Инициализация подключения к локальному Redis
cache = redis.Redis(host='localhost', port=6379, db=0)

def get_product_info(product_id):
    cache_key = f"product:{product_id}"
    
    # 1. Проверяем наличие данных в кэше
    cached_product = cache.get(cache_key)
    
    if cached_product:
        print("Возврат данных из кэша Redis")
        return json.loads(cached_product)
        
    # 2. Если данных нет, имитируем запрос к основной (медленной) БД
    print("Запрос к основной базе данных...")
    time.sleep(1) # Имитация задержки
    product_data = {"id": product_id, "name": "Смартфон", "price": 499}
    
    # 3. Сохраняем данные в Redis с временем жизни 60 секунд
    cache.setex(cache_key, 60, json.dumps(product_data))
    
    return product_data

# Первый вызов (медленный, идет в БД)
print(get_product_info(101))

# Второй вызов (быстрый, берется из Redis)
print(get_product_info(101))
```
