# SQLite

## Определение
SQLite — это легковесная, встраиваемая (embedded) реляционная система управления базами данных (СУБД). В отличие от классических клиент-серверных СУБД (таких как PostgreSQL или MySQL), движок SQLite работает непосредственно внутри процесса приложения и хранит всю базу данных (таблицы, индексы, триггеры и данные) в едином кроссплатформенном файле на диске. Она написана на языке C, не требует запуска отдельного серверного процесса и обладает нулевой конфигурацией.

## Зачем нужно
SQLite используется там, где необходима надежная, структурированная база данных, но развертывание и поддержка отдельного сервера избыточны или невозможны. Основные сценарии применения:
- **Мобильные и десктопные приложения:** Стандарт де-факто для локального хранения данных в iOS, Android, macOS и Windows, а также в браузерах (Chrome, Firefox, Safari) и мессенджерах.
- **Встраиваемые системы и IoT:** Идеально подходит для устройств с ограниченными ресурсами (умные часы, телевизоры, автомобильные мультимедийные системы).
- **Прототипирование и тестирование:** Позволяет разработчикам быстро создавать базы данных «в памяти» для модульных тестов или на ранних стадиях разработки веб-приложений.
- **Формат файлов для приложений:** Часто используется как формат сохранения файлов (например, `.sqlite`, `.db`) в различных программах, включая ГИС и финансовые приложения.

## Пример
Работа с SQLite не требует установки или запуска сервера. Вот пример использования SQLite на языке Python с помощью встроенного модуля `sqlite3`:

```python
import sqlite3

# Подключение к базе данных (если файла нет, он будет создан)
connection = sqlite3.connect('example.db')
cursor = connection.cursor()

# Создание таблицы
cursor.execute('''CREATE TABLE IF NOT EXISTS users
                  (id INTEGER PRIMARY KEY, name TEXT, age INTEGER)''')

# Вставка данных
cursor.execute("INSERT INTO users (name, age) VALUES ('Alice', 28)")
cursor.execute("INSERT INTO users (name, age) VALUES ('Bob', 34)")

# Сохранение изменений
connection.commit()

# Выборка данных
cursor.execute("SELECT * FROM users WHERE age > 30")
print(cursor.fetchall())  # Вывод: [(2, 'Bob', 34)]

# Закрытие соединения
connection.close()
```

Пример выполнения стандартных SQL-запросов (например, через CLI-утилиту `sqlite3`):
```sql
-- Создание таблицы
CREATE TABLE projects (id INTEGER PRIMARY KEY, title TEXT);

-- Вставка записи
INSERT INTO projects (title) VALUES ('New Project');

-- Чтение записей
SELECT * FROM projects;
```
